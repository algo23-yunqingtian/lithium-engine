## 1. 任务与方法

### 1.1 任务定义

模拟真实生产流程：每一交易日 T，**只使用该日之前的全部历史数据**，重新估算：

1. **产业主体预期函数 D_f 的参数 alpha**
2. **投机主体预期函数 D_c 的参数 beta**
3. **Logit 自适应标准化窗口**的分位参照系

用重估参数生成 T 日的分歧 D 因子与交易信号，**严格禁止使用未来数据**。对比历史一次性回测（全样本固定 alpha=0.3 / beta=0.5 + 全样本滚动分位），评估模型每日估参的稳定性。

### 1.2 HAM 分歧因子（与 exp409 一致）

```
D_f[T] = alpha * (P_fund[T] - close[T])        # 产业基本面回归压力
D_c[T] = beta  * (close[T] - close[T-1])        # 投机趋势动量
disagreement = dcn - dfn   (dcn/dfn = rolling.rank(pct) 标准化后的 D_c/D_f)
deviation = |dcn - dfn|
```

方向约定：`D_c > D_f`（动量主导）→ 多；`D_f > D_c`（回归主导）→ 空。

### 1.3 滚动估参方法（无未来数据）

对每个交易日 T，用 `[max(0, T-180), T)` 的历史 `close`/`P_fund` 拟合 alpha/beta：

- **目标函数**：使分歧度符号 `sign(D_c - D_f)` 预测**次日价格变动符号** `sign(close[T+1] - close[T])` 的**误分类最少**（Logit 式监督拟合）。
- **解空间**：alpha∈[0.10, 0.60]、beta∈[0.30, 0.80]，各 11 档网格。这是拟合解空间，**非事后调参**——每日在给定历史内求最优解，不使用 T 日之后的任何信息。
- **无前视保证**：估参训练窗口为 `[T-180, T)`（不含 T 自身及之后）；T 日的 D_f/D_c 由新参数即时计算。

> **诚实披露**：网格化搜索使最小化目标成为整数损失面，alpha/beta 会在网格边界附近跳动（alpha_min=0.10 常贴边界），这是**网格量化噪声**，非真实市场结构变化。下文第 3 节证明该噪声不影响信号。

### 1.4 信号计算链路（全部沿用原版，无前视）

估参得到的 D_f/D_c 代入 exp409 原版信号链路，**逐日重估的仅是参数，其余逻辑零改动**：

```
rolling_deviation (估参) → compute_aux_signals → load_gmm_states
  → compute_ham_signals → run_ham_dynamic → T1风控底座(exp413) → ADX降权(×0.3)
```

基本面腿（exp410）、GMM 状态、风控底座、ADX 降权、9:01 成交 + 10bp 滑点全部与一次性基准**完全一致**，确保对照纯净。9:01 成交价固定种子（20260910），全组共用同一套外推价格。

## 3. 估参稳定性分析（模块 2）

### 3.1 参数数值波动

| 参数 | 均值 | 标准差 | CV | 范围 | 偏离固定值 |
|:---|:---:|:---:|:---:|:---:|:---:|
| alpha（产业） | 0.178 | 0.147 | **0.826** | [0.10, 0.55] | -40.8% |
| beta（投机） | 0.347 | 0.084 | **0.244** | [0.30, 0.50] | -30.7% |

alpha 的数值 CV=0.826 看似极不稳定，但这是**误导性表象**：

### 3.2 关键洞察：参数噪声被标准化吸收

HAM 的分歧因子经 `rolling(180).rank(pct)` 标准化——这是**排名归一化**，只依赖 D_c/D_f 在滚动窗口内的**相对次序**，与线性缩放的**绝对值无关**。因此：

- alpha/beta 的精确数值变化（如 alpha 从 0.10 跳到 0.55）→ 只改变 D_f 的整体缩放 → **被 rank 归一化完全吸收** → 不改变分歧因子的相对排序 → **不传导到信号**。
- 实测印证：尽管 alpha CV=0.826，**信号方向一致率 100%、Jaccard 0.931、净值相关 0.995**。

> **方法学含义**：评判 HAM 估参稳定性，应以**信号/净值一致性**为主判据，而非参数数值 CV。rank 标准化赋予 HAM 对参数估计噪声的天然鲁棒性——这是框架的设计优势，也是"每日估参安全"的根因。

### 3.3 无前视保证（审计要点）

| 环节 | 是否用未来数据 | 说明 |
|:---|:---:|:---|
| alpha/beta 估参 | ❌ 无 | 训练窗口 `[T-180, T)`，不含 T 及之后 |
| D_f/D_c 计算 | ❌ 无 | 用 T 日及更早的 close/P_fund + 当日估出的参数 |
| Logit 标准化 | ❌ 无 | `rolling(180).rank(pct)` 仅用 T 及更早窗口 |
| 辅助/GMM/信号/风控/ADX | ❌ 无 | 全部沿用 exp409/exp413 原版无前视实现 |
| 9:01 成交价 | ⚠️ 外推 | 统计外推（固定种子），偏离分布来自真实分钟数据 |

## 4. 稳定性判定

```
判定: STABLE
理由: 滚动每日估参生成的高度无未来数据信号，与一次性回测高度一致：
      同持仓日方向一致率 100%，持仓 Jaccard=0.931，净值相关=0.9950，
      年化 Δ=+5.2pp。HAM 经 rolling.rank(pct) 标准化后对 alpha/beta 精确值
      不敏感，参数数值波动（网格量化噪声）被标准化吸收，不传导到信号层。
      模型可实盘滚动运行。
```

**实盘含义**：HAM-T1 可安全地以"每日重新估参"方式生产信号。每日收盘后用当日及之前的历史拟合 alpha/beta，生成次日交易信号，无需依赖全样本事后参数，符合真实交易的时间结构。

## 5. 局限性（诚实披露）

1. **网格估参的噪声本质**：alpha/beta 数值波动主要来自 11×11 网格量化 + 整数误分类损失的平坦面，非真实市场参数漂移。若改用连续优化（如 scipy 最小化连续损失），参数轨迹会更平滑，但不改变信号结论。
2. **9:01 成交价为统计外推**：真实分钟数据仅覆盖 ~4 个交易日，全回测期采用偏离分布外推（固定种子），非逐日真实成交价。
3. **滚动估参窗口固定 180 日**：未测试更长/更短窗口对估参稳定性的影响。
4. **年化 +5.2pp 的稳健性**：滚动优于一次性可能部分来自估参"恰好"捕捉到样本内特征，需在 exp427-1 极端行情压力测试中进一步验证。
5. **P_fund 产业锚**：沿用 HAM 因子表的 P_fund（非真实成本曲线重建），其本身可能含代理偏差。

## 7. 复现命令与坑点

```bash
cd /home/ubuntu/lithium-engine
/usr/bin/python3 model_ham/exp428_shadow_trading/exp428_engine.py
```

**坑点**：
- 必须 `/usr/bin/python3`（有 pandas/scipy/numpy/matplotlib；venv 的 python3.11 缺 pandas）。
- Pyright 报 `Import pandas/exp4xx could not be resolved` 全是 sys.path 动态导入误报，**全忽略**。
- 估参 O(n×11×11)≈8.7万次内层 + 信号链路，运行约 30-60 秒，建议后台跑。
- `df_ham_roll` 是 720 行全 HAM 因子表（2023-09 起），`pos_roll/pos_oneshot` 对齐到 ctx idx（628 行，2024-02 起）——信号序列 CSV 须用 `set_index("date").reindex(idx)` 对齐，勿按位置赋值（否则 Length mismatch 720 vs 628）。
- 方向一致率计算：`both_hold` 须用**布尔掩码**参与 `&`，勿用 `.sum()` 后的标量整数（否则整数 `&` 得错误结果）。
- 估参稳定性的主判据是**信号一致性**（方向一致率/Jaccard/净值相关），不是参数数值 CV——rank 标准化已吸收参数噪声。
