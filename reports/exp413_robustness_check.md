## 1. 口径说明（回撤数值的两种口径）

本报告所有回撤均标注口径，避免混淆：

| 口径 | 计算方式 | exp412 V4 数值 |
|------|---------|:---:|
| **全时段净值最大回撤**（本报告主用） | `max_drawdown_full`：全 628 日净值序列的峰谷最大跌幅 | **-0.1156** |
| **同日路径回撤**（exp412 报告用） | 引擎内 `equity[t-1]` 路径计算的日内回撤 | -0.131 |

两者差异源于：全时段口径在「仓位归零日」计入 0 收益，平滑了峰谷；同日路径口径捕捉了日内更极端的回撤点。**本报告统一采用全时段口径**（与 exp412 的 `exp412_metrics.json` 中 `max_drawdown_full` 一致），所有扫描/成本/情景对比同口径，可比性优先。

### 3.3 模块2 结论

> **策略对交易成本的耐受边界远超 0.4%/边（在测试区间内未失效）。**
>
> - **组合年化转负成本阈值：> 0.4%（未触达）**。即使成本翻倍到 0.30%，组合年化仍为 0.610（+61%/年）。
> - **HAM 年化转负成本阈值：> 0.4%（未触达）**。HAM 从 0 成本的 1.072 衰减到 0.4% 的 0.667，仍高度为正。

> - **实操含义**：策略在 0.20%/边（双倍实际成本）仍有年化 71.6%、Calmar 6.03 的优秀表现。**成本不是该策略的失效边界**；若要找到真正的失效点，需测试到 0.6%+ 的极端成本（超出常规期货品种滑点范围）。

## 4. 模块3：情景压力拆分

### 4.1 行情划分

沿用 exp411/412 的 `market_regime`：基于价格 20 日动量，阈值 ±12% 划分单边上涨（uptrend）/单边下跌（downtrend）/震荡（range）。

### 4.2 分行情绩效（exp412 V4 vs exp411 无风控基线）

| 行情 | 天数 | exp412年化 | exp412夏普 | exp412回撤 | exp412交易 | exp411年化 | exp411夏普 | exp411回撤 | exp411交易 |
|------|:---:|:---:|:---:|:---:|:---:|:---:|:---:|:---:|:---:|
| 上涨 uptrend | 110 | 2.476 | 3.574 | -0.123 | 9 | 3.421 | 3.230 | -0.189 | 9 |
| 下跌 downtrend | 58 | 0.678 | 2.732 | -0.045 | 5 | 0.682 | 2.742 | -0.045 | 5 |
| 震荡 range | 460 | 0.506 | 2.426 | -0.089 | 26 | 0.697 | 2.481 | -0.112 | 26 |

### 4.3 模块3 结论

> **策略的短板是震荡段的收益率，而非趋势段。**
>
> - **上涨段是策略强项**：年化 2.476、夏普 3.574，但回撤最深（-0.123）。风控有效：exp411 基线在上涨段回撤 -0.189，exp412 压到 -0.123（-35%）。
> - **下跌段表现均衡**：年化 0.678、夏普 2.732、回撤仅 -0.045。空头暴露有限但风险调整后收益稳定。风控对下跌段几乎无影响（年化 0.678 vs 0.682，回撤基本一致）—— 说明下跌段本身回撤就小，风控用不上。
> - **震荡段是收益短板**：年化 0.506（最低），夏普 2.426（最低），但回撤最浅（-0.089）。注意 exp412 在震荡段的年化（0.506）**低于** exp411 基线（0.697，-27%），回撤则从 -0.112 改善到 -0.089（-20%）—— 震荡段风控的代价最高，收益牺牲最大。
> - **核心短板**：震荡段 460 天（占 73%）贡献了 26 笔交易（占 65%），是交易最密集但收益率最低的区间。**策略本质是「趋势捕获型」，在长期震荡市中 Alpha 效率显著下降。** 若要改善，需在震荡段引入额外的区间方向信号或降低震荡段换手。
> - **风控的代价分布**：风控在趋势段（尤其上涨段）节省大量回撤而几乎不牺牲收益（甚至 exp412 上涨段夏普 3.574 > 基线 3.230）；在震荡段则牺牲收益换回撤。**风控在趋势环境是纯增益，在震荡环境是必要代价。**

| 单笔标准差 | 5.13% |

### 5.2 模块4 结论

> **HAM 单笔尾部风险可控，但全局账户风控对极端单笔约束有限。**
>
> - **最大单笔亏损 -8.58%**：相对全账户最大回撤 -11.6%，单笔亏损占账户回撤的 74%。这意味着若 HAM 出现连亏序列，账户回撤可能快速逼近 M2 硬止损线（18%）。
> - **但实际账户回撤仅 -11.6%**（远低于单笔极端 -8.58% 的 2 倍），说明：① HAM 单笔 -8.58% 不是孤立事件，是分散在多笔中的；② M2 回撤风控在 HAM 连亏时已介入降仓。
> - **盈亏比 2.989 + 胜率 40%**：HAM 是典型的「低胜率高盈亏比」尾部策略，单笔亏损虽可达 -8.58%，但平均亏损仅 -1.72%，第5分位亏损 -2.65% —— 极端尾部占比小（40 笔中仅个位数触及 -8%）。
> - **全局风控约束力评估**：M2 硬止损回撤阈值 18%，而 HAM 单笔最大 -8.58%。若连续 2 笔极端亏损，累计约 -16.5%，逼近但仍未触发 M2 hard stop（18%）。**M2 回撤风控能约束 HAM 的连续尾部风险，但单笔极端 -8.58% 发生在账户层面会被稀释到 <11.6% 回撤** —— 风控体系对尾部风险是「事后降仓」而非「事前止损」，在极端连亏场景下仍可能滞后。
> - **改进方向**：若要事前约束 HAM 单笔尾部，需对 HAM 子策略设置单笔止损（如单笔 -5% 强制平仓），但 exp409 当前无此机制（HAM 靠偏离度回归/GMM跃迁/反向信号/12日强制平仓平仓）。这是 exp411 遗留待办的「HAM 单笔尾部风险对冲」方向。

## 6. 模块5：完整交易判定逻辑溯源

> 本节逐条说明整套策略每一步的判定依据，明确每个决策节点的输入变量，区分因子信号与账户风控。

### 6.1 整体架构（三层）

```
┌─────────────────────────────────────────────────────────┐
│  第一层：因子信号生成（exp409 HAM + exp410 基本面）        │
│    输入：价格 close、P_fund、Total_Demand、三因子          │
│    输出：HAM 日度目标仓位 h_target / 基本面日度目标仓位 f_target │
├─────────────────────────────────────────────────────────┤
│  第二层：组合仓位合成（exp411 规则）                        │
│    输入：h_target, f_target                               │
│    输出：组合日度目标仓位 pos                               │
├─────────────────────────────────────────────────────────┤
│  第三层：账户风控（exp412 M2+M3）                          │
│    输入：pos, 价格价格价格价格价格价格价格价格价格（波动率）,     │
│          账户净值 equity（回撤）                            │
│    输出：最终仓位 risk_pos                                 │
└─────────────────────────────────────────────────────────┘
```

### 6.2 第一层A：HAM 子策略判定逻辑（因子信号决定）

**输入变量**：`close`（收盘价）、`P_fund`（基本面回归价）、`Total_Demand`（总需求）

```
# ===== HAM 系统偏离度构造 =====
# D_f = alpha * (P_fund - close)          # 产业基本面回归压力 (alpha=0.3)
# D_c = beta * (close[t] - close[t-1])     # 投机趋势动量 (beta=0.5)
# D_c_norm = rolling_rank(D_c, 180日, min_periods=60) * 2 - 1   # [-1,1]
# D_f_norm = rolling_rank(D_f, 180日, min_periods=60) * 2 - 1   # [-1,1]
# disagreement = D_c_norm - D_f_norm        # 分歧方向
# deviation = |disagreement|                # 系统失衡程度

# ===== 辅助信号 =====
# ret5 = log(close).diff(5)
# vol_anomaly = (|ret5| > rolling_quantile(|ret5|, 180日, 0.90))  # 波动率异动
# td_flip = sign(Total_Demand) != sign.shift(1)                     # 仓单边际变号

# ===== 主信号（分位阈值，滚动180日） =====
# q_med = rolling_quantile(deviation, 180日, min_periods=60, 0.90)
# q_high = rolling_quantile(deviation, 180日, min_periods=60, 0.95)
# q_neutral = rolling_quantile(deviation, 180日, min_periods=60, 0.40)

# ===== 方向判定 =====
# signal_dir = +1 (多) if disagreement > 0 (动量主导/投机追涨)
#            = -1 (空) if disagreement < 0 (回归主导/产业定价)
#            = 0   if disagreement == 0

# ===== 开仓条件（双信号共振） =====
# main_trigger = (deviation > q_med) AND q_med.notna()
# aux_confirm = vol_anomaly OR td_flip
# open_signal = main_trigger AND aux_confirm        # 弱信号(未双共振)禁止开仓

# ===== 仓位分级 =====
# position_size = 1.0 (100%) if deviation > q_high (极度失衡)
#               = 0.6 (60%)  if deviation <= q_high (中度失衡)
#               = 0.0 (禁开)  if deviation <= q_med (弱失衡)
```

**HAM 开仓触发**（T 日收盘决策）：`open_signal[T] == True` 时，T 日按 `signal_dir[T] * position_size[T]` 建仓。

**HAM 平仓触发**（T 日收盘决策，任意一条触发即平仓，成交价=T 日 close）：

```
# 1. 偏离度回归中性区间
if deviation[T] < q_neutral[T]:           → 平仓 (neutral_revert)

# 2. GMM 状态跃迁（S0/S1/S3 切换，排除 S2）
if gmm_state_proxy[T] != gmm_state_proxy[entry_t] AND gmm_state_proxy[T] in [0,1,3]:
                                            → 平仓 (gmm_transition)

# 3. 反向边际信号（方向翻转，逻辑失效）
if signal_dir[T] != entry_dir AND signal_dir[T] != 0:
                                            → 平仓 (reverse_signal)

# 4. 最大持仓 12 个交易日
if (T - entry_t) >= 12:                  → 平仓 (max_hold)
```

### 6.3 第一层B：基本面子策略判定逻辑（因子信号决定）

**输入变量**：`f_stock_pct20`（库存20日环比）、`f_wh_basis_x_stockpct`（仓单基差×仓单增速）、`f_cell_pct20`（动力电池20日环比）、`close`

```
# ===== 三因子合成 =====
# 单因子信号 factor_signal(f, t) = sign(cur - rolling_median(180日)) * IC_SIGN
#   IC_SIGN = {库存: -1, 仓单基差: +1, 动力电池: -1}
# combo_signal = mean(三因子信号)            # 取值 [-1, 1]（离散±1/3步进）
# combo_abs = |combo_signal|

# ===== 分位阈值（滚动180日） =====
# q_med = rolling_quantile(combo_abs, 180日, min_periods=60, 0.80)
# q_strong = rolling_quantile(combo_abs, 180日, min_periods=60, 0.95)
# q_ret20 = rolling_quantile(ret20, 180日, min_periods=60, 0.90)

# ===== 方向判定 =====
# signal_dir = +1 (多) if combo_signal > 0
#            = -1 (空) if combo_signal < 0

# ===== 开仓条件（强边际共振） =====
# open_trigger = (combo_abs > q_med) AND q_med.notna()

# ===== 仓位分级 =====
# position_size = 1.0 (100%) if combo_abs > q_strong (强信号)
#               = 0.7 (70%)  if combo_abs <= q_strong (中等信号)
#               = 0.0 (禁开)  if combo_abs <= q_med (弱信号)
```

**基本面开仓触发**（T 日收盘决策）：`open_trigger[T] == True` 时，T 日按 `sign(combo_signal[T]) * position_size[T]` 建仓。

**基本面平仓触发**（T 日收盘决策，任意一条触发即平仓）：

```
# 1. 基本面边际衰减（逻辑消退）
if entry_combo != 0 AND combo_signal[T] == 0:        → 平仓 (marginal_decay)

# 2. 预期透支平仓（行情提前兑现）
#    realized = sign(entry_combo) * log(close[T] / close[entry_t])
if entry_t > 0 AND realized > q_ret20[T]:           → 平仓 (expect_realized)

# 3. 反向信号触发（合成强度符号反转）
if entry_combo != 0 AND sign(combo_signal[T]) != sign(entry_combo):
                                                  → 平仓 (reverse_signal)

# 4. 最长保护性持仓 18 日
if (T - entry_t) >= 18:                            → 平仓 (max_hold)
```

### 6.4 第二层：组合仓位合成逻辑（因子信号决定，非风控）

```
# 每日重新对齐（日度目标仓位法），输入 h = h_target[T], f = f_target[T]
if |h| > 1e-9 AND |f| > 1e-9:
    if sign(h) == sign(f):                          # 同向共振
        pos = sign(h) * min(|h| + |f|, 1.0)         # 仓位相加，上限100%
    else:                                           # 反向共振（对冲）
        net = h + f
        pos = clip(net, -1.0, 1.0)                  # 净头寸 = 两腿相减
elif |h| > 1e-9:
    pos = h                                        # 仅HAM触发 → 按HAM仓位
elif |f| > 1e-9:
    pos = f                                        # 仅基本面触发 → 按基本面仓位
else:
    pos = 0.0                                      # 无信号 → 空仓
```

### 6.5 第三层：账户风控逻辑（账户风控决定，非因子信号）

#### M3：高波动环境控仓

```
# 输入：price（收盘价）
# realized_vol = rolling_std(pct_change(price), 20日, min_periods=5) * sqrt(250)
# vol_mult = 0.50 if realized_vol > 0.55 else 1.0    # 高波动压缩50%
pos_after_vol = pos * vol_mult[T]
```

#### M2：账户级回撤风控

```
# 输入：equity[T-1]（截至T-1的账户净值）, equity[window]（60日窗口）
# 使用截至 T-1 的净值，不含当日 → 无前视
if T > 0:
    window = equity[max(0, T-60) : T]              # 不含当日 [start, T)
    peak = max(window)
    current_dd = (equity[T-1] - peak) / peak       # 用 T-1 净值算回撤
    dd_abs = -current_dd                            # 正值
    if dd_abs <= 0.05: dd_mult = 1.00              # 回撤≤5%: 正常仓位
    elif dd_abs <= 0.12: dd_mult = 0.70            # 回撤12%: 轻度降仓
    else: dd_mult = 0.30                           # 回撤>18%: 硬止损
final_pos = pos_after_vol * dd_mult
```

### 6.6 净值更新与成本

```
# T 日仓位吃 T 日（T-1→T）价格收益，无前视
r_price = (close[T] - close[T-1]) / close[T-1]      # 已实现收益
strat_ret = risk_pos[T] * r_price                   # T日仓位×T日已实现收益
dpos = |risk_pos[T] - risk_pos[T-1]|                # 仓位变动
cost_ret = 2 * COST * dpos                          # 双边成本，换仓换手时扣除
equity[T] = equity[T-1] * (1 + strat_ret - cost_ret)
```

### 6.7 因子信号 vs 账户风控的边界总结

| 决策节点 | 决定来源 | 输入变量 | 是否可被风控覆盖 |
|---------|---------|---------|:---:|
| 做多/做空方向 | **因子信号** | HAM: disagreement符号; 基本面: combo_signal符号 | 否（风控不改变方向） |
| HAM 开仓 | **因子信号** | main_trigger + aux_confirm | 否 |
| HAM 平仓 | **因子信号** | 偏离度回归/GMM跃迁/反向信号/12日 | 否 |
| 基本面开仓 | **因子信号** | open_trigger | 否 |
| 基本面平仓 | **因子信号** | 边际衰减/透支/反向/18日 | 否 |
| 组合仓位合成 | **因子信号** | h, f 合成规则 | 否（风控作用于合成后） |
| 仓位规模分级 | **因子信号** | 偏离度/合成强度分位 → 60/70/100% | 否 |
| M3 波动压缩 | **账户风控** | realized_vol(20日) > 55% → ×0.50 | 是（覆盖因子仓位） |
| M2 回撤降仓 | **账户风控** | equity[T-1] 回撤阶梯 → ×0.70/×0.30 | 是（覆盖因子仓位） |

**关键区分**：因子信号决定「方向+规模+开关」（开什么仓、多大、什么时候开平），账户风控决定「最终仓位的乘数」（M3/M2 在因子仓位之上再乘降仓系数）。**风控从不改变方向、从不替代信号开关**，只做仓位压缩。

### 7.3 V2 时序等价性校验（最硬证据）

**方法**：把 h_target / f_target 整体 `shift(1)`（当日信号=昨天算出来的，即把全部输入延迟一天），检验 shift 后的仓位序列是否等于原始仓位序列的平移（pos_shifted[t] == pos_orig[t-1]）。

- **隔离风控后的信号合成层匹配率：1.000000（100% 完全一致）** —— 把 M2/M3 风控参数设为不触发（dd_recover=1.0, vol_upper=10.0），纯信号合成层 shift 后完美平移，证明 `pos[t]` 只依赖 ≤t 的数据。
- **含风控的全仓位匹配率：0.8198** —— 差异来自 M2 回撤用 `equity`（含成本，非shift）、M3 波动用 `price`（非shift）计算，这些风控因子本身依赖 T 日价格/净值而非未来，属正确行为。

**V2 结论**：信号合成层 `pos[t] = f(h[≤t], f[≤t])` 严格满足时序等价性。**不存在用未来信号生成当日仓位的情况。**

### 7.4 V3 净值时序校验

| 项 | 引擎实现 | 时序判断 |
|----|---------|---------|
| 价格收益 | `r_price = (close[T]-close[T-1])/close[T-1]` | T-1→T 已实现，不含未来 ✓ |
| 策略收益 | `strat_ret = pos[T] * r_price[T]` | T日仓位吃T日已实现收益 ✓ |

**数值复核**：前 10 日净值用独立公式手动重算，与引擎净值完全一致（atol=1e-9）。

**V3 结论**：净值计算严格使用 T-1→T 已实现收益，M2 回撤用 T-1 净值。**无未来价格/未来净值进入当日决策。**
