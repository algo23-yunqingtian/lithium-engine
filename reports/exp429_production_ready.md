## 2. 每日运行流水线

### 2.1 三步输出

每日收盘后运行 `run_daily.py`，产出三件核心交付：

**① 分歧 D 因子序列**（`exp429_daily_pipeline.csv`）
- `D_c`：投机主体预期 = β_t × (close[t] − close[t−1])
- `D_f`：产业主体预期 = α_t × (P_fund[t] − close[t])
- `disagreement` = D_c_norm − D_f_norm（标准化后分歧）
- `deviation` = |disagreement|（分歧强度）
- `alpha_t` / `beta_t`：Logit 动态权重（每日滚动估参，严格无前视）

**② 交易信号**
- `open_signal` / `signal_dir`：HAM 引擎开仓信号与方向
- `main_trigger` / `aux_confirm`：主触发器与辅助确认

**③ 建议仓位**（两套配置并行输出）
- `pos_A`：配置A（稳健，ADX 降权 ×0.3）
- `pos_B`：配置B（激进，关闭 ADX 降权）
- `action_A` / `action_B`：可读交易动作（OPEN_LONG / CLOSE / REVERSE / INCREASE / DECREASE / HOLD）

### 2.2 时序铁律（版本B口径）

```
T 日收盘 -> 滚动估参(仅用 [T-180, T) 历史) -> 生成 D 因子与信号
  -> T+1 9:01 分钟均价成交 (+10bp 滑点)
```
- **无前视保证**：每日 α_t/β_t 仅用历史，不含当日及之后数据（继承 exp428 STABLE 结论）。
- **rank 标准化**：分歧因子经 `rolling.rank(pct)` 排名标准化，对 α/β 精确值不敏感（exp428 关键洞察），参数数值噪声被吸收、不传导到信号层。

## 3. 两套配置绩效验证

口径：9:01 分钟均价 + 10bp 滑点，无前视，滚动每日估参（exp428 口径）。区间 2024-02-01 ~ 2026-09-07（628 日）。

| 指标 | 配置A（稳健） | 配置B（激进） | Δ |
|:---|:---:|:---:|:---:|
| 年化收益 | **34.0%** | **37.4%** | +3.4pp |
| 夏普 | 2.293 | 2.212 | −0.08 |
| 最大回撤 | **−6.8%** | **−10.5%** | +3.7pp（恶化） |
| Calmar | **4.98** | 3.55 | −1.43 |
| 累计收益 | 108.8% | 122.0% | +13.2pp |
| 笔数 | 135 | 132 | −3 |
| 日度 IC | +0.219 | +0.241 | +0.022 |
| 持仓日 | 232 | 232 | 0 |

**回撤与 exp426 锚点完全一致**（配置A −6.8% / 配置B −10.5%），验证 ADX 降权是唯一变量。年化高于 exp426 一次性锚点（28.9%/32.1%）源于**滚动每日估参优势**（exp428 已证明 +5.2pp），回撤不变——滚动估参只提升收益不放大风险。

**结论**：
- **配置A（稳健）**：Calmar 4.98，风险调整最优，**推荐实盘主力**。
- **配置B（激进）**：牺牲 Calmar（4.98→3.55）换 3.4pp 年化，回撤放大 3.7pp，**高风险高收益，适合激进资金**。

### 4.2 漂移告警阈值与判定

| 指标 | WARNING | CRITICAL | 方向 |
|:---|:---:|:---:|:---|
| IC_roll | < 0.05 | < 0.0 | 越低越危险 |
| dev_median | > 0.95 | > 1.05（或 < 0.25） | 过高=趋势盲区/过低=无机会 |
| α/β CV | > 0.50 | > 0.80 | 过高=权重剧烈切换 |

三级告警：任一维度 CRITICAL → 整体 CRITICAL；任一 WARNING → WARNING；否则 OK。

## 6. 诚实局限

1. **9:01 成交价为统计外推**：真实分钟数据仅 ~4 个交易日（标定 mean_dev_pct=+0.039%），全期外推（固定种子）。
2. **滚动估参年化优势未样本外独立验证**：34.0%/37.4% 含样本内估参特征，实盘初期须以影子盘对照真实成交验证。
3. **告警阈值为分位校准**：IC/DEV/CV 阈值基于全样本分位 + 经济含义，非统计检验；实盘应定期用新数据重校准。
4. **P_fund 产业锚沿用代理**：非真实成本曲线重建，可能含代理偏差。
5. **持续影子盘为离线模拟**：未接入真实撮合/资金流，信号与真实成交可能有时滞与滑点差异。
