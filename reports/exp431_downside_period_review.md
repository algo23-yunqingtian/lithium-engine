## 2. IC 时序复盘

### 2.1 IC 有效性完全反转

| 指标 | 影子盘观测 | 回测基准 | 偏离 |
|:---|---:|---:|---:|
| IC 负值日 | **18/20 天（90%）** | 正值 85.7% | 完全反转 |
| IC 连续负值 | **18 天**（08-18 ~ 09-10，未中断） | 极少连续 | 极端 |
| IC 起点 | +0.438（08-14） | 均值 0.238 | 正常起势 |
| IC 谷值 | -0.202（08-18 ~ 09-07） | 全样本 min -0.243 | 接近历史极值 |
| IC 终值 | -0.050（09-08 ~ 09-10） | — | **收敛但未转正** |

### 2.2 IC 三段演变

```
08-14 ~ 08-17   IC = +0.438, +0.079   正常有效（因子有预测力）
08-18           IC = -0.202            【首次转负】因子开始反向
08-19 ~ 09-07   IC = -0.202 (恒定)     【深度失效】15 日稳定负值
09-08 ~ 09-10   IC = -0.050            【收敛期】绝对值缩小 75%，但未达 OK 阈值 0.05
```

**关键判读**：IC 在 09-08 起从 -0.202 收敛至 -0.050（改善 75%），**存在因子自愈迹象**——对应市场跌势放缓（09-04 后单日跌幅从 -5.3% 收窄至 -1% 以内）与基差重新锚定。但仍未达到 OK 阈值（IC ≥ 0.05），**尚不满足恢复开仓条件**。

### 2.3 信号方向与价格的实际背离

在 IC 负值期间，`signal_dir` 频繁在 +1/-1 间翻转，而价格处于单边下行：

| 日期 | 信号方向 | 次日实际 | 结果 |
|:---|:---:|:---:|:---|
| 08-19 | -1（做空） | 08-20 +1.00% | ✗ 反向 |
| 08-20 | +1（做多） | 08-21 +4.28% | ✓ 偶然 |
| 08-21 | +1（做多） | 08-24 +0.11% | ✓ 偶然 |
| 08-24 | +1（做多） | 08-25 -5.40% | ✗ 反向 |
| 08-25 | -1（做空） | 08-26 +1.25% | ✗ 反向 |

信号方向与价格实际收益**系统性反向**——这正是 IC<0 的定义，也解释了为何 R4 必须强制暂停：若按信号执行，多数日子将亏损。

### 3.1 告警分布对比

| 级别 | 影子盘 | 占比 | 回测基准 | 偏离 |
|:---|---:|---:|---:|---:|
| OK | 2 | 10% | 67% | -57pp |
| WARNING | 0 | 0% | 20% | -20pp |
| **CRITICAL** | **18** | **90%** | 13% | **+77pp** |

### 3.2 触发源结构

| 触发源 | 次数 | 占比 |
|:---|---:|---:|
| **IC_CRIT** | 18 | 100% |
| DEV_CRIT / DEV_WARN | 0 | 0% |
| CV_CRIT / CV_WARN | 0 | 0% |

**单一因子主导**：全部 18 天 CRITICAL 均由 IC_CRIT（IC_roll < 0）触发，D 分布与权重 CV 两个维度**全程未触发**。这印证失效是**纯因子有效性问题**，而非市场博弈失衡（D 分布）或权重剧烈切换（CV）。

### 3.3 告警时序

```
08-14 OK        IC=+0.438  基线正常
08-17 OK        IC=+0.079  仍为正
────── IC 转负分界线 ──────
08-18 CRITICAL  IC=-0.202  【连续第1日】
08-19 CRITICAL  IC=-0.202  【连续第2日】
08-20 CRITICAL  IC=-0.202  【连续第3日 → R4 触发】
08-21 ~ 09-10 CRITICAL     持续 17 日未中断
```

**注意 WARNING 完全缺失**：本次失效是**突发型**（IC 从 +0.079 直接跳到 -0.202），没有经过 WARNING 缓冲区。这与告警阈值设计一致（IC_WARN=0.05，IC_CRIT=0.0，中间无过渡），但对实盘而言意味着**缺乏预警缓冲**。

## 4. R4 风控触发原因分析

### 4.1 R4 规则

```
R4: 漂移告警 CRITICAL 连续 ≥ 3 个交易日 → 强制暂停交易（pos 置 0）
```

来源：exp429 实盘手册 §8.1「10 条禁止交易红线」，基于 exp418 全样本分位校准。

### 4.2 触发链

```
[08-18] IC 转负 -0.202 → 告警 CRITICAL (第1日)
[08-19] IC 持续 -0.202 → 告警 CRITICAL (第2日)
[08-20] IC 持续 -0.202 → 告警 CRITICAL (第3日)
         ↓
    【R4 判定：CRITICAL 连续 ≥ 3 日 → 触发暂停交易】
         ↓
    pos_A = pos_B = 0，HOLD_FLAT，此后不再开仓
```

- **触发日**：2026-08-20（区间第 5 个交易日）
- **首次触发距失效起点**：2 个交易日（08-18 失效 → 08-20 触发），**响应及时**

### 4.3 触发原因分层

**直接原因**：IC 滚动值跌破 0（因子预测力转负）。

**深层原因（判断层）**：
1. **HAM 信号依赖"产业-投机分歧收敛"的均值回归逻辑**。单边趋势下跌中，产业主体（D_f）与投机主体（D_c）**同向下行**，分歧度虽高但方向无预测力——典型的 exp418「趋势盲区」。
2. **D_f 回归逻辑在跌势中被趋势压倒**：09-04 前 D_f 为负（-3234 ~ -6000，现货高于期货，产业回归压力向下），与投机压力同向；09-04 基差转负后 D_f 转正（+1624 ~ +2090），但此时价格已跌幅过半，**回归锚已滞后**。
3. **这不是模型 bug**：模型准确计算了 D_f/D_c/信号，问题在于市场状态超出了分歧信号的适用域。

### 4.4 风控正确性验证（反事实）

| 情景 | 若 R4 未触发 | 实际（R4 触发） |
|:---|---:|---:|
| 08-20 起按信号开仓 | 信号方向系统性反向，18 日内预计亏损 8~12% | 空仓 |
| 最大可能亏损 | ≈ 峰谷跌幅 -12.24% | 0% |
| NAV 终值 | ≈ ¥880,000 | **¥1,000,000** |
| 最大回撤 | ≈ -12% | **0%** |

**结论：R4 规则在本次单边下跌中避免了约 12% 的潜在亏损。风控体系有效性得到真实行情验证。**

## 7. 关键认知沉淀

1. **"极端行情"必须细分类型**：exp427-1 验证的极端是**双向剧烈震荡**（HAM 强项，年化 50.8%），本案是**单边趋势下跌**（HAM 弱项）。模型对前者鲁棒，对后者依赖风控兜底。这两类极端的市场微观结构完全不同。

2. **零回撤 ≠ 策略有效**：20 日零回撤是风控"拒绝做"的结果。绩效评估必须等策略重新开仓后。把"没亏钱"当作"策略有效"是本次复盘必须避免的认知陷阱。

3. **基差转负是结构切换的领先信号**：09-04 基差从 +2.66% 跳至 -2.78%，期货跌破现货，标志市场从"投机性高升水"转向"现货供需再平衡"。这个信号**早于 IC 收敛**（09-08）出现，值得纳入监控。

4. **告警 WARNING 缓冲缺失是设计弱点**：本次失效从 OK 直接跳到 CRITICAL，无 WARNING 过渡。IC 阈值 0.05/0.0 之间无缓冲带，实盘中意味着缺乏预警窗口。此为后续可优化项（非本次改动）。

5. **连续统计优于单日告警**：单日 CRITICAL 可能是噪声，但**连续天数**是失效持续度的可靠度量。IC 连续负值 18 天 > 禁止交易红线 5 天，确认这是持续性失效而非偶发波动。
