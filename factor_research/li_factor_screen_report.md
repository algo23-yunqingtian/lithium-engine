- **F1 开工率**：覆盖率 21.3%，受限于周频数据的日频前向填充。
- **F2 排产**：覆盖率 32.7%，同样受限于周频频率。

## 3. 检验方法论

### 3.1 HAM 经验教训约束

本检验严格遵循 HAM 项目（exp410-exp437）总结的6条经验教训：

1. ✅ **尾部 20% 盲测**：按时间排序，前 80% 为训练集，后 20% 为盲测试集
2. ✅ **置换检验**：500 次随机置换，训练集上计算
3. ✅ **Bonferroni 校正**：置换 p × 因子总数(6)，校正多重检验
4. ✅ **正交残差 IC**：用 close/5日动量/20日动量回归收益率，取残差后计算因子 IC
5. ✅ **区分因子类型**：F1-F5 为收益预测因子，F6 为风控状态因子
6. ✅ **信号反转检测**：训练 IC × 盲测 IC < 0 即标记为信号反转

### 3.2 判定规则

| 判定 | 条件 |
|:---|:---|
| ✅ accept | 全部通过：无信号反转 + 置换 p<0.05 + Bonferroni p<0.05 + 正交残差IC>0.03 + 盲测IC>0.02 |
| ❌ reject | 未通过上述任一条件但无信号反转 |
| ❌ reject_critical | 信号反转（训练/盲测IC异号） |
| ❌ reject_insufficient | 有效样本 < 30 |

## 4. 逐因子详细结果

### F1: 上游锂矿+盐湖合并开工率 20 日环比

| 指标 | 值 |
|:---|:---:|
| 样本数 | 162 |
| 全样本 IC | +0.0664 (p=0.403) |
| 训练集 IC | +0.0691 (p=0.439) |
| **盲测集 IC** | **-0.0330 (p=0.855)** |
| IR | 0.5643 |
| 置换 p | 0.428 |
| Bonferroni p | 1.000 |
| 信号反转 | ⚠️ 是（反转比 0.48） |
| 正交残差 IC | +0.0501 (p=0.528) |

**分析**：训练集 IC 微弱正显著但盲测反转，置换 p 远超 0.05。开工率作为供给侧因子在日频收益预测中不显著。低频基本面（周频 ffill 到日频）的有效信号被噪声淹没。

### F2: 动力电池排产 20 日环比

| 指标 | 值 |
|:---|:---:|
| 样本数 | 249 |
| 全样本 IC | -0.1138 (p=0.073) |
| 训练集 IC | -0.1267 (p=0.075) |
| **盲测集 IC** | **-0.0017 (p=0.991)** |
| IR | -0.6505 |
| 置换 p | 0.080 |
| Bonferroni p | 0.480 |
| 信号反转 | 否 |
| 正交残差 IC | -0.0844 (p=0.184) |

**分析**：训练集 IC 接近显著（p=0.075），方向为负（排产增→价格跌，符合"利好出尽"逻辑）。但盲测 IC 退化至 -0.002，信号完全消失。这是典型的样本内过拟合——训练集边际显著但样本外无预测力。

### F3: 库存预期差因子

| 指标 | 值 |
|:---|:---:|
| 样本数 | 24 |
| 全样本 IC | N/A |
| 盲测集 IC | N/A |

**分析**：有效样本仅 23 个（< 30），无法完成检验。根因是周频库存数据在日频序列上覆盖率极低。需要更长的日频库存数据才能评估此因子。建议后续接入日频仓单数据作为替代。

### F4: 现货成交溢价因子

| 指标 | 值 |
|:---|:---:|
| 样本数 | 476 |
| 全样本 IC | +0.0145 (p=0.753) |
| 训练集 IC | +0.0093 (p=0.857) |
| **盲测集 IC** | **+0.0503 (p=0.628)** |
| IR | 1.0654 |
| 置换 p | 0.858 |
| Bonferroni p | 1.000 |
| 信号反转 | 否 |
| 正交残差 IC | +0.0370 (p=0.431) |

**分析**：现货溢价因子全样本 IC 接近零。虽然 IR=1.07（绝对值最高），但 IC 绝对值太小（<0.02），无实际预测意义。现货-期货价差在日频层面与收益率的非线性关系微弱。

### F5: 动态跨期价差 + 跨期曲率

| 指标 | 值 |
|:---|:---:|
| 样本数 | 732 |
| 全样本 IC | -0.0855** (p=0.021) |
| 训练集 IC | -0.1127** (p=0.006) |
| **盲测集 IC** | **+0.0531 (p=0.523)** |
| IR | -0.4258 |
| 置换 p | 0.014 |
| Bonferroni p | 0.084 |
| 信号反转 | ⚠️ 是（反转比 0.47） |
| 正交残差 IC | -0.0732 (p=0.051) |

**分析**：这是最值得警惕的因子。全样本 IC=-0.086 在 5% 水平显著，训练集 IC=-0.113 在 1% 水平显著，置换 p=0.014。如果只看全样本和训练集，这个因子看起来"可用"。但盲测 IC=+0.053（符号反转），与 HAM 项目的信号反转模式完全一致。

**Bonferroni 校正后 p=0.084 > 0.05，不显著。** 即使没有信号反转，也无法通过多重检验校正。

### F6: 拥挤度因子

| 指标 | 值 |
|:---|:---:|
| 样本数 | 754 |
| 全样本 IC | +0.0100 (p=0.784) |
| 训练集 IC | +0.0036 (p=0.929) |
| **盲测集 IC** | **+0.0555 (p=0.499)** |
| IR | 0.5214 |
| 置换 p | 0.942 |
| Bonferroni p | 1.000 |
| 信号反转 | 否 |
| 正交残差 IC | +0.0187 (p=0.611) |

**分析**：拥挤度因子 IC 接近零，正交残差 IC 也极低。作为风控状态因子（非收益预测因子），其价值在于状态监测而非收益预测。建议保留为风控辅助指标，不进入收益预测因子库。

## 5. 与 HAM 项目的对比

| 维度 | HAM 项目 | 本次因子检验 |
|:---|:---|:---|
| 因子数 | 19 特征 → 正交筛选后 1 个 | 6 个候选 → 0 个通过 |
| 信号反转 | 训练 IC=+0.450 → 盲测 IC=-0.592 | F1: +0.069→-0.033; F5: -0.113→+0.053 |
| 反转模式 | 完全反转 | 完全反转（2/6 因子） |
| Bonferroni | 未做（HAM 教训） | 已做，全部 p>0.05 |
| 正交残差 IC | 0.055 (p=0.192) | F5 最佳: 0.073 (p=0.051) 仍不显著 |
| 结论 | 不做预测因子 | 不做预测因子 |

**核心结论**：碳酸锂期货的基本面因子在当前数据深度（~763 交易日）下存在与 HAM 项目完全一致的样本不稳定性。信号反转不是 HAM 特有的问题，而是碳酸锂期货市场的结构性特征——低数据深度 + 高噪声 + 制度变化频繁。

## 6. 过拟合风险评估

| 风险维度 | 评估 | 说明 |
|:---|:---:|:---|
| 自由度增量 | 低 | 6 个因子独立构建，无交互项 |
| 样本量 | 不足 | 763 交易日，其中有效覆盖 162-754 不等 |
| 多重检验 | 已控制 | Bonferroni 校正，6 因子 |
| 数据窥探 | 低 | 因子定义来自交接文档，非数据挖掘 |
| 样本外验证 | ✅ 严格 | 尾部 20% 盲测，完全不参与因子筛选 |
| 前向填充偏差 | 中等 | 周频 ffill 到日频引入插值偏差，但 ffill 方向正确 |

**总体风险**：低过拟合风险。本检验的"零通过"结论本身不是过拟合的产物——恰恰相反，严格盲测暴露了样本内显著性的虚假性（F5 全样本 p=0.021 但盲测反转）。

## 8. 结论与后续建议

### 结论

**6 个候选因子无一通过单因子检验。** 碳酸锂期货基本面因子在当前数据深度下不具备可靠的日频收益预测能力。这一结论与 HAM 项目的核心发现完全一致——信号反转是市场结构性特征，而非特定模型的缺陷。

### 后续建议

1. **不做收益预测因子研发**：与 HAM 项目结论一致，不再投入资源研发日频收益预测因子
2. **保留 F5/F6 为风控观察指标**：期限结构和拥挤度作为市场状态监测工具有辅助价值
3. **F3 库存预期差待数据**：若后续获取日频库存数据（如仓单数据），可重新检验
4. **降低频率**：日频噪声过大，建议尝试周频或月频因子检验
5. **影子盘观测**：与 HAM 一致，保留 F5/F6 在影子盘中持续采集样本外数据
