# 🧠 碳酸锂多主体博弈 · 用户说明书

> 这份文档面向**使用者**，不讲代码，只讲每个板块在做什么、图表怎么看、背后的交易逻辑是什么。

---

## 一、系统一句话解释

这套系统模拟了碳酸锂市场上**7种不同身份的市场参与者**（Agent），让它们在每天根据各自的信息和规则做出判断和交易决策，然后通过12个图表来展示"多方和空方谁更强"。

**打个比方**：就像搭了一个"碳酸锂微观世界"，里面有矿工、冶炼厂、贸易商、基金、散户、套利者、政策制定者，它们各自按自己的利益行事，互相博弈，你作为观察者在旁边看全局战况。

## 二、7大Agent角色说明书

| Agent | 角色 | 它关心什么 | 它看多时会 | 它看空时会 |
|-------|------|-----------|-----------|-----------|
| 📡 **冶炼厂** (smelter) | 产业供给端 | 冶炼利润、库存、月差 | 减产惜售（减少供给→利多） | 加大产出（增加供给→利空） |
| 🏔️ **锂矿/资源商** (resource) | 上游原料 | 矿石成本线、产能利用率 | 惜售矿石（抬高成本→利多） | 抛售矿石（降低成本→利空） |
| 🏪 **贸易商/加工商** (merchant) | 中间流通 | 基差（现货vs期货）、月差结构 | 采购囤货（增加需求→利多） | 抛售库存（释放供给→利空） |
| 🏦 **纯投机构** (institution) | 金融资本 | 价格动量、成交量、持仓量变化 | 趋势跟踪做多 | 趋势跟踪做空 |
| 🏛️ **政策/宏观** (policy) | 政策面 | 宏观政策、新能源车销量、进出口 | 政策利好预期 | 政策收紧预期 |
| 👥 **散户/游资** (retail) | 情绪面 | 新闻情绪、持仓排名变化 | 追涨 | 杀跌 |
| ⚖️ **套利商** (arbitrage) | 量化套利 | 月差结构合理性、季节性规律 | 套利做多（价差回归） | 套利做空（价差回归） |

### 观点分（view_score）怎么理解

- 范围 **-100 ~ +100**
- **+30以上**：强烈看多（该Agent会大幅做多）
- **+15~30**：轻度看多
- **0**：中性，观望
- **-15~-30**：轻度看空
- **-30以下**：强烈看空（该Agent会大幅做空）

### 持仓（position）怎么理解

- **正数** = 持有多单（看涨持仓）
- **负数** = 持有空单（看跌持仓）
- 数值越大 = 仓位越重

### 板块①：顶部汇总卡片（6张）

| 卡片 | 含义 | 怎么看 |
|------|------|-------|
| 最新价 | 今日碳酸锂期货收盘价 | 显示为"X万" |
| 多方总仓位 | 所有看多Agent的持仓总和 | 绿色数字 |

**用法**：一眼判断多空力量对比。净多头寸 > 0 且平均观点分 > 20 → 市场整体偏多。

### 板块②：7大Agent实时状态（卡片网格）

每个卡片是一个Agent的**当日快照**：

- **左边彩色条**：绿=看多，红=看空，黄=中性
- **观点分**：该Agent当天打分（-100~100）
- **持仓量**：正=多单，负=空单
- **浮盈亏**：模拟计算的未实现盈亏（%）
- **成本价**：该Agent的建仓均价
- **底部进度条**：观点分可视化（越往右越看多）
- **引号文字**：该Agent今天的操作理由（如"去库叠加上涨，基本面改善"）

**点击卡片**会弹出详情，可以看到风控参数（止损线、止盈线、资金量等）。

**用法**：逐个Agent看它今天的情绪和仓位变化。如果冶炼厂和矿商同时看多，说明产业端在唱多；如果机构和散户同时看空，说明金融资金在撤离。

### 板块③：持仓对比（横向柱状图）

**这张图在做什么**：把7个Agent当天的持仓量画成横向柱状图，左边是空单（红色），右边是多单（绿色）。

**怎么看**：
- 柱子往右 → 该Agent今天持有多单
- 柱子往左 → 该Agent今天持有空单
- 柱子越长 → 仓位越重
- 鼠标悬停可以看到观点分和观点文字

**交易含义**：如果冶炼厂、资源商、贸易商都在右边（多），而散户在左边（空），说明**产业资金在看多，情绪资金在看空**——这通常是反转信号（产业和散户逆向时往往产业更靠谱）。

---

### 板块④：多空力量对比（饼图）

**这张图在做什么**：把所有Agent的多单汇总 vs 空单汇总，看一个总体占比。

**怎么看**：
- 绿色 = 多方总仓位
- 红色 = 空方总仓位
- 百分比 = 占比

**交易含义**：饼图显示"多方占70%"不代表市场一定涨（持仓重可能意味着接近顶部）。**多空比极端偏离时（如8:2）反而是反转信号**，系统会自动触发"极化检测"。

---

### 板块⑤：观点评分分布（柱状图）

**这张图在做什么**：7个Agent今天的观点分一目了然地对比。

**怎么看**：
- 柱子颜色：绿=看多，红=看空，黄=中性
- 柱子高度 = 观点分绝对值
- 柱子顶端数字 = 具体分值

**交易含义**：这个图帮你判断**市场共识度**。
- 7个柱子都在绿色 → 高度一致看多 → 可能已过度多头
- 7个柱子参差不齐（有的绿有的红）→ 意见分歧 → 市场震荡概率大
- 如果多数Agent在+20以上 → 一致偏多，趋势可能延续

### 板块⑥：历史观点甘特图（时间线散点图）

**这张图在做什么**：展示**最近22天**（7月1日到30日）7个Agent观点分的走势变化。横轴是日期，纵轴是Agent，散点颜色是观点方向。

**怎么看**：
- 横轴 = 日期（从左到右是过去→今天）
- 纵轴 = 7个Agent（每个Agent一行）
- 散点颜色：深绿=强烈看多(+30+)，浅绿=轻度看多，黄色=中性，红色=看空
- 散点高度 = 观点分大小
- 连线 = 同一Agent连续几天的观点走势
- 鼠标悬停 → 看具体日期、分值、观点文字

**交易含义**：
- **看趋势**：某个Agent的散点整体往上升 → 该Agent越来越看多
- **看分歧**：某天所有Agent的散点高低差很大 → 那天市场意见极不一致
- **看切换**：某个Agent从红色变成绿色 → 该Agent今天**改变了立场**（比如从看空变成看多），这通常是重要信号
- **看一致性**：某天所有Agent的散点颜色都一样 → 市场高度一致

**举例**：如果7月25日冶炼厂从红色点变成绿色点，且持仓量增加，说明冶炼厂**今天开始转看多**——可能是因为利润恢复或库存下降。

### 板块⑦：交易逻辑强度分析（K线 + 7维时序线 + 热力图）

#### 7-1：LC0日K线

标准的K线图，最近60个交易日。红色=跌，绿色=涨。用于对照Agent观点是否跟价格走势吻合。

#### 7-2：7维逻辑强度时序线

**在做什么**：把市场观点从"谁在看多/空"拆解成**7个交易逻辑维度**，每个维度每天有一个强度评分（-100~100）。

**7个维度**：
| 维度 | 颜色 | 含义 | 谁主导 |
|------|------|------|--------|
| 供给风险 | 红色 | 供给端收紧/扰动有多严重 | 冶炼厂、矿商 |
| 需求下滑 | 橙红 | 下游需求不及预期有多严重 | 机构 |
| 库存 | 黄色 | 去库/累库趋势 | 贸易商、冶炼厂 |
| 宏观政策 | 蓝色 | 政策面利多/利空 | 政策Agent |
| 成本支撑 | 绿色 | 成本线附近的支撑强度 | 矿商 |
| 情绪 | 紫色 | 新闻情绪/消息驱动 | 散户 |
| 基差月差 | 青色 | 现货vs期货价差结构 | 套利商、贸易商 |

**怎么看**：
- 数值 > 0（在零线上方）= 该逻辑**利多**
- 数值 < 0（在零线下方）= 该逻辑**利空**
- 绝对值越大 = 该逻辑越强
- 鼠标悬停 → 看当天各维度的精确值

**交易含义**：
- 如果"供给风险"和"成本支撑"两条线都在+30以上 → 基本面利多逻辑很强
- 如果"需求下滑"和"情绪"在-20以下 → 但"供给"在+30以上 → 矛盾信号，市场可能震荡
- 如果所有7条线都收敛到+20以上 → 全维度偏多，趋势确定性强
- 如果"情绪"（紫色）远高于其他 → 行情靠情绪驱动，可能虚高

**你之前说的"看不到数据"**：这是因为 `notes` 表（情绪源数据）在7月份是空的，导致"情绪"维度评分为零。加上其他维度评分逻辑比较简单（大部分返回0），所以线条看起来平平的。**这说明当前评分函数还不够敏感，或者基本面数据确实没什么变化。**

#### 7-3：逻辑热力图（日期×逻辑维度）

**在做什么**：同上7个维度，但用热力图的方式展示——**颜色越绿=越利多，越红=越利空**。

**怎么看**：
- 横轴 = 日期
- 纵轴 = 7个逻辑维度
- 颜色深浅 = 强度大小
- 数字 = 精确评分

**你之前说"看不到数据"**：同样的原因——评分值太小或全为0，热力图的颜色差异看不出来。**这本身就是信息**：说明当前市场的7个逻辑维度都没有特别强的信号，市场处于方向不明朗的震荡期。

### 板块⑧：博弈互动矩阵

#### 8-1：Agent互动热力图（日期×Agent）

**在做什么**：展示Agent之间的**互动关系**——当某个Agent做出看多/看空判断时，对其他Agent产生了什么影响。

**两种互动类型**：
| 类型 | 颜色 | 含义 | 举例 |
|------|------|------|------|
| 信息冲突 (info_conflict) | 红色系 | 两个Agent观点相反 → 说明市场信息不对称 | 冶炼厂看多但散户看空 → 冶炼厂掌握的信息和散户不同 |
| 行为跟随 (behavior_follow) | 绿色系 | 两个Agent方向一致（都增仓或都减仓）→ 说明有跟风效应 | 散户追涨，机构也追涨 → 散户在跟随机构 |

**怎么看**：
- 横轴 = 日期
- 纵轴 = Agent
- 绿色格子 = 那天这个Agent受到了互动影响
- 格子越亮 = 互动强度越大（数值越高）
- 鼠标悬停 → 看互动类型和强度

**交易含义**：
- 如果散户（retail）的格子经常亮绿色 → 散户在频繁跟随大户 → 典型的追涨杀跌
- 如果某个Agent的格子经常亮红色 → 它经常跟别人观点相反 → 可能有独立信息来源
- 格子密集的区域 → 那段时间市场博弈激烈

#### 8-2：影响力网络图（力导向图）

**在做什么**：把7个Agent的关系画成一张**关系网**——谁影响谁、关系是冲突还是跟随。

**怎么看**：
- 7个圆圈 = 7个Agent
- 红线（弯曲）= 信息冲突（观点相反）
- 绿线（直）= 行为跟随（方向一致）
- 线越粗 = 互动越强
- **线会动**：因为这个图用了ECharts的力导向布局，节点会不断物理模拟漂移——这是**正常的视觉效果**，不代表数据在变化
- 鼠标悬停在某个Agent上 → 高亮显示它的所有关系

**你之前说"跑来跑去"**：这是**正常的**。ECharts的 `layout: 'force'` 是一个物理模拟——节点之间有斥力（互相推开）和连线拉力（保持距离），会一直微微漂移。这不是bug，是可视化风格。**这不代表数据在实时变化。**

**交易含义**：
- 如果某个Agent有很多红线连出去 → 它是市场的"异见分子"，经常跟主流观点对立
- 如果绿线密集 → 市场存在强烈的**羊群效应**（大家都跟风）
- 如果网络图几乎没线 → Agent之间基本独立操作，没有明显的博弈互动
- **注意**：如果图看起来很空旷或线条极少，说明**当前数据量不足**——7个Agent的观点方向太接近或太少互动触发条件，需要更多交易日数据才能看到有意义的网络

### 板块⑨：博弈因子分析

#### 9-1：三色警示条（极化检测）

**在做什么**：这是系统的"警报器"。当多空分歧极端严重时自动触发。

**三种状态**：
| 状态 | 颜色 | 触发条件 | 含义 |
|------|------|----------|------|
| 平静 | 蓝色 | 无特殊 | 市场正常 |
| 警惕 | 黄色 | 最大修正幅度 > 2 | 博弈修正开始出现 |
| 极化 | 红色 | 多空比 > 3:1 且 分歧激烈 | 市场过度集中，建议人工审核 |

#### 9-2：博弈因子热力图（Agent × 因子）

**在做什么**：展示每个Agent的**基础分**（自己独立判断）如何被**博弈因子**修正。

**5个因子列**：
| 列 | 含义 |
|----|------|
| 基础分 (base_score) | Agent靠自己算的原始观点分 |
| 信息传递 (info_transfer) | 因为"别人跟我看反了"而产生的修正值 |
| 行为影响 (behavioral_impact) | 因为"别人跟我做同样方向"而产生的修正值 |
| 总修正 (total_correction) | 以上两个修正的总和 |
| 修正后分 (corrected_score) | 基础分 + 总修正 = 最终观点分 |

**怎么看**：
- 每个Agent一行，5个因子的值用颜色表示
- 如果"信息传递"是红色（负值）= 该Agent被反向信息拉低了分数
- 如果"行为影响"是绿色（正值）= 该Agent因为别人跟风而被推高了分数

**交易含义**：
- 如果修正幅度很小（5分以内）→ 博弈互动不强烈，各自为战
- 如果修正幅度很大（>10分）→ 博弈影响很大，某个Agent被群体意见显著改变
- 如果修正方向与基础分相反 → 该Agent**被群体说服了**（比如自己看多但被修正为中性）

#### 9-3：修正幅度趋势（30日）

**在做什么**：展示**过去每天**博弈修正的最大幅度——"那天Agent之间博弈有多激烈"。

**四条线**：
| 线 | 含义 |
|----|------|
| 最大\|修正\|（黄柱） | 那天所有Agent中，修正幅度的最大值 |
| 最大\|信息\|（蓝线） | 信息传递修正的最大值 |
| 最大\|行为\|（紫线） | 行为影响修正的最大值 |
| 观点分歧（红线） | 7个Agent最高分和最低分的差值 |

**为什么要有这个设计**：
- 每个Agent不是闭门造车——它要"参考"别人的观点
- 如果你的观点跟大多数人相反，系统会给你扣一点分（"你是不是漏了什么信息？"）
- 如果你的观点跟大多数人一致且都在加仓，系统会给你加一点分（"大家跟你一样，趋势可能成立"）
- **这个趋势图告诉你哪天博弈最激烈**——如果某天修正幅度突然爆增，说明那天市场发生了重大分歧，有人被大量"说服"

**你之前说"没什么数据和变化"**：因为：
1. 当前数据只有22天，波动本身就不大
2. 敏感度参数可能偏保守（retail=0.9但smelter=0.3），产业Agent不容易被影响
3. 如果7个Agent观点方向基本一致，修正自然很小

**正常预期**：当市场出现重大事件（如政策突变、库存急变、价格暴涨暴跌）时，修正幅度应该会出现 spikes。如果始终平平的，说明当前评分函数/参数还没捕捉到足够的分歧。

## 四、Agent之间的互动——系统是怎么实现的

### 三层博弈机制

#### Layer 1：信息传递（"别人看反了，我是不是漏了什么？"）

**原理**：如果你的观点跟大多数Agent相反 → 你可能掌握了别人没有的信息 → 但也要警惕自己可能错了。

**具体操作**：
- 假设你自己看多（score=+40）
- 但另外5个Agent平均看空（score=-30）
- 那你的修正公式：`修正 = -(反向资金占比 × 敏感度 × 8)`
- 如果你是散户（敏感度0.9），反向资金占60% → 修正 = -0.6 × 0.9 × 8 = **-4.3**
- 你的修正后分 = 40 - 4.3 = **35.7**（被拉低了一点点）

**交易含义**：这个机制模拟了"群体智慧"——当你的判断和大多数专业人士相反时，系统建议你稍微保守一点。

#### Layer 2：行为跟随（"大家都在加仓，我是不是也要跟风？"）

**原理**：如果大部分Agent跟你做同样的方向（都增仓多单或都减仓），说明有趋势在形成。

**具体操作**：
- 你自己增仓了100手多单
- 另外3个Agent也增仓了多单（同向）
- 这些Agent的资金权重 × 仓位动量 → 综合成"行为影响"
- 如果你是散户（敏感度0.9），其他大户也在加仓 → 修正可能是 **+5**
- 你的修正后分 = 40 + 5 = **45**（被推高了）

**交易含义**：这个机制模拟了"羊群效应"——散户跟着大户跑，机构跟着趋势跑。但注意，**大户的敏感度低**（smelter=0.2），意味着产业Agent不会被散户带节奏。

#### Layer 3：极化检测（"所有人都往一边倒，是不是过头了？"）

**触发条件**：
- 多空比 > 3:1（比如5个看多、1个看空、1个中性）
- 且平均绝对分 > 30

**效果**：给多数派减5分、少数派加5分 → **反转信号**。

**交易含义**：这模拟了"极端看多就是利空"的逻辑——当所有人都看多的时候，买盘已经耗尽，反而是卖点。

### 互动数据是怎么记录到数据库的

1. 每天运行 `agent_daily_update.py` → 7个Agent各自独立评分
2. 评分结束后调用 `apply_game_factors()` → 计算Layer 1/2/3
3. 写入 `agent_interactions` 表：每天每条互动关系（from_agent → to_agent, 类型, 强度）
4. 前端通过 `/api/agent-interactions` 读取 → 生成热力图和网络图

### 你说到的"彼此对彼此行为的预期"能不能体现

**目前的系统能做到**：
- ✅ Agent之间互相影响评分（信息传递 + 行为跟随）
- ✅ 记录哪些Agent互相对抗（信息冲突）
- ✅ 记录哪些Agent互相跟随（行为跟随）
- ✅ 极化时自动反转信号

**目前做不到的**：
- ❌ 没有显式的"预期"建模——Agent不是"预测别人会怎么做"，而是"看别人已经做了什么"
- ❌ 没有博弈树或纳什均衡计算
- 这是 Phase 6 回测时可以考虑的方向

## 五、构造Agent行为模式的完整框架

### 每个Agent由三部分构成

```
行为模式 = 信息集（看到什么数据） + 规则引擎（怎么分析） + 输出（判断+仓位）
```

### 信息集（每个Agent能看到的市场数据）

| 数据源 | 来源 | 所有Agent都能看到 | 只有特定Agent用 |
|--------|------|:---:|:---:|
| 期货价格（LC0, LC2609等） | prices / contract_prices 表 | ✅ | |
| 成交量/持仓量 | 同上 | ✅ | institution, arbitrage |
| 现货升贴水 | spreads 表 | | merchant, arbitrage |
| 库存变化 | inventory_history 表 | | smelter, merchant |
| 新闻情绪分 | notes 表 | | retail, policy |
| 宏观政策信号 | 外部API | | policy |
| 成本线（冶炼/矿山） | 计算得出 | | smelter, resource |
| 其他Agent的状态 | agent_history 表 | ✅ | 博弈因子模块用 |

### 规则引擎（以冶炼厂为例）

```
冶炼厂决策逻辑：
1. 看利润：冶炼利润 > 0 → 看多信号，< -300 → 看空信号
2. 看库存：库存连续下降 → 利多，上升 → 利空
3. 看月差：现货升水远月（contango）→ 正常，贴水（backwardation）→ 惜售利多
4. 看情绪：新闻正面 → 利多
5. 综合加权得出 -100 ~ +100 的观点分
6. 根据观点分决定持仓量（+200手 / 0 / -100手 等）
7. 检查止损止盈，调整仓位
```

### 预期（Expectation）——系统的处理方式

系统用的是**简化版预期**：
- Agent不预测"明天别人会怎么做"
- 而是看"今天别人已经做了什么"，然后修正自己的观点
- 这相当于"后视镜式预期"——基于已发生的互动调整判断

如果要加入更精细的预期（比如"我认为散户明天会追涨，所以我提前减仓"），那需要：
1. 给每个Agent加一个"对别人行为的预判"模块
2. 这需要更复杂的博弈论建模（纳什均衡、贝叶斯博弈）
3. 属于Phase 6回测后的进阶方向

## 六、常见使用场景和解读

### 场景1：趋势行情判断

**步骤**：
1. 看顶部汇总 → 净多头寸方向
2. 看观点评分分布 → 共识度（7个柱子方向是否一致）
3. 看甘特图 → 最近趋势（散点是否持续上升/下降）
4. 看逻辑热力图 → 哪个维度最强（供给？需求？情绪？）

**判断**：
- 净多 > 0 + 共识度高 + 供给风险维度强 = **趋势利多，做多胜率较高**
- 净空 > 0 + 情绪维度远强于基本面 = **情绪驱动下跌，可能超跌反弹**

### 场景2：反转信号识别

**步骤**：
1. 看多空力量对比饼图 → 多空比是否极端（>5:1）
2. 看警示条 → 是否触发"极化"（红色）
3. 看甘特图 → 产业Agent是否跟散户方向相反
4. 看互动网络图 → 冲突线（红线）是否突然增多

**判断**：
- 极度偏多 + 警示条红色 + 产业Agent看空 = **见顶信号**
- 极度偏空 + 警示条红色 + 矿商看多 = **见底信号**

### 场景3：震荡市识别

**特征**：
- 净多头寸在0附近来回变
- 7个Agent观点分参差不齐（有的+20有的-10）
- 逻辑热力图颜色浅（没有维度特别强）
- 修正幅度趋势线始终很低
- 互动网络图线条稀疏

## 七、当前系统限制和注意事项

1. **情绪数据缺失**：`notes` 表7月份是空的，导致"情绪"维度评分全为0。这是逻辑热力图"看不清"的主因。
2. **数据天数不足**：只有22个交易日，博弈因子和互动网络图的数据量偏少。建议跑满30天以上再看。
3. **修正幅度小是正常的**：产业Agent（smelter, resource）敏感度低（0.2-0.3），不容易被影响。只有散户和机构才会被大幅修正。
4. **网络图"跑来跑去"是正常效果**：ECharts力导向布局的动画效果，不代表数据变化。
5. **每个Agent的"观点文字"是规则生成的**，不是LLM写的，所以比较模板化。Phase 7的LLM审核可以改善。
6. **pnl_unreal（浮盈亏）是模拟计算**，不是真实交易结果，仅供参考。
