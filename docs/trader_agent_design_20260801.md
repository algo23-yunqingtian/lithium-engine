## 一、贸易商的角色定位

贸易商是市场里**唯一同时做现货和期货**的主体，利润来源是**价差**而非方向：
- 基差（现货-期货）
- 月差（近月-远月）
- 库存周期（屯货增值/去库避险）
- 仓单博弈（注册/注销对近月价格的影响）

**行为特征**：价格大涨时它是**天然的卖方**（手上囤的货就是空头），价格大跌时它是**买方**（逢低补库）。它和 CTA 的趋势跟随天然相反——CTA 涨了追多，贸易商涨了抛货。

## 二、行为逻辑（5 层决策）

### 层 1：基差交易（现货 vs 期货）
| 信号 | 逻辑 | 行为 |
|---|---|---|
| 现货升水扩大（基差 > 阈值） | 现货紧缺 | 持有现货 + 期货做空（锁定利润）→ 期货偏空 |
| 现货贴水扩大（基差 < 阈值） | 现货过剩 | 卖出现货 + 期货做多（抄底）→ 期货偏多 |

> ⚠️ 现有代码**没有**真正接入现货数据，只用月差 proxy（spread_2609_2610 代替基差）。`spot_price` 表已存在但 0 行——这是改造点 1。

### 层 2：月差结构交易（近月 vs 远月）— 现有逻辑
| 信号 | 逻辑 | 行为 | 分值 |
|---|---|---|---|
| 远月贴水 >500（backwardation 深） | 现货偏强，持货有利 | 持有现货 → 偏多 | +25 |
| 远月升水 >300（contango 深） | 持货成本高 | 抛售 → 偏空 | -25 |
| 小作文利多 >0.3 | 情绪支撑 | 加分 | +15 |
| 小作文利空 <-0.3 | 情绪压制 | 减分 | -15 |
| 当日大涨 >2% | 获利了结窗口 | 减分（抛货） | -10 |
| 当日大跌 <-2% | 逢低补货窗口 | 加分（扫货） | +10 |

### 层 3：屯库存周期（新增行为）
引入库存状态机，用 `inventory_history` + 基差/月差方向判断：
| 状态 | 触发条件 | 行为 |
|---|---|---|
| **主动建库** | 远月升水（contango）+ 现货贴水 + 库存低位 | 囤货，等基差回归 → 偏多期货远月 |
| **持库观望** | 基差中性 + 月差平缓 | 维持现有库存 |
| **主动去库** | 远月贴水（backwardation）+ 现货升水 + 库存高位 | 抛货，赚基差 → 偏空期货近月 |
| **恐慌去库** | 库存快速累增 + 价格下跌 | 清库避险 → 强偏空 |

### 层 4：正套/反套观点（新增，替代原 arbitrage 职能）
| 观点 | 触发条件 | 逻辑 |
|---|---|---|
| **正套（买近卖远）** | 月差（远-近）> 持有成本（约 800-1000 元/吨） | 价差过大将回归 → 赚收敛 |
| **反套（卖近买远）** | 月差 < 0 且深度贴水（<-800） | 近月被过度打压 → 赚修复 |
| 持仓：view_score 中性（±20），主要反映在**月差敞口**而非方向敞口 |

### 层 5：赌仓单（新增行为，联动 lc_position.db）
| 信号 | 逻辑 | 行为 |
|---|---|---|
| 仓单注册量连续增加（today_qty 上升） | 交割压力 → 近月承压 | 偏空近月 / 反套 |
| 仓单注销量连续增加（delta 为负） | 现货需求消化 → 近月支撑 | 偏多近月 / 正套 |
| 仓单绝对量接近历史高位 | 交割库爆满 → 多头逼仓风险 | 偏空近月 |

## 三、仓位管理（现有机制 + 贸易商特化）

### 通用仓位框架（所有 agent 共用）
```
pos_change = int(new_score / 100 × max_position × 0.3)   # 每次最多变动 30% 仓位
new_pos = clamp(old_pos + pos_change, -max_position, +max_position)
```
- **惯性限制**：view_score 每天最多跳变 ±20（防止情绪化翻转）
- **止损**：浮亏 > stop_loss_pct → 全平（merchant: 6%）
- **止盈**：浮盈 > take_profit_pct → 减半（merchant: 12%）

### 贸易商专属风险参数（现有）
```json
{
  "max_position": 150,          // 上限 150 手
  "stop_loss_pct": 0.06,        // 止损 6%
  "take_profit_pct": 0.12,      // 止盈 12%
  "basis_sensitivity": 0.35,    // 基差敏感度
  "term_structure_sensitivity": 0.25  // 月差结构敏感度
}
```

### 贸易商特化建议（改造点 2）
1. **上限按风险预算分层**：套利头寸（正反套）风险小 → 可给高上限；方向头寸（赌单边）风险大 → 低上限
2. **双账户模型**：现货库存（不可做空，只能增减）+ 期货头寸（可多可空）——现有代码只有单一 position，改造后应拆分 `spot_inventory` 和 `futures_position` 两个字段
3. **止盈阈值更低**：贸易商赚价差，不贪趋势 → take_profit 应比 CTA（20%）更早落袋（建议 8-10%）
4. **基差走阔时降杠杆**：基差极端（>2%）时价差回归确定性高 → 加大套利仓；方向仓减半
