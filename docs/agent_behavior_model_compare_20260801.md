## 一、现有 7 个 Agent 的行为模型（代码级）

### 通用框架
每个 agent 每日评分 `view_score ∈ [-100, +100]`，由三层叠加：
1. **硬编码规则层**（各 agent 专属 if-else，见下）
2. **基本面六维 z-score 加权层**（滚动 250 日标准化：supply/demand/inventory/profit/sentiment/basis/composite，正值=利多）
   - 贡献 = z × weight × 30
3. **博弈互动层**（game_factors：反向资金压制 + 同向跟随 + 极化反转）

`AGENT_CLAMP`（评分上下限）本身编码了**性格偏置**——clamp 区间不对称 = 该 agent 长期倾向。

---

### 1. smelter 冶炼厂（clamp: -60 ~ +80，长期偏多）
| 场景 | 行为 | 分值 |
|---|---|---|
| 价涨+增仓 | 多头强势→增产意愿强→**看空**（供给增加预期） | +30 |
| 价跌+减仓 | 减产预期→**看多** | -25 |
| 累库+跌 | 基本面恶化→看空 | -20 |
| 去库+涨 | 基本面改善→看多 | +20 |
| 窄幅震荡 | 供给刚性强→中性偏多 | +5 |
| 基本面加权 | supply -0.3 / profit +0.4 / inventory -0.2 | |

**行为本质**：反身性供给者——价格越高越想增产（看空），价格越低减产（看多）。不是追涨杀跌，是"供给端对冲"。

### 2. merchant 贸易商/加工商（clamp: -50 ~ +60）
| 场景 | 行为 | 分值 |
|---|---|---|
| 远月贴水 >500（backwardation 深） | 现货偏强→持有现货→**偏多** | +25 |
| 远月升水 >300（contango 深） | 持货成本高→抛售→**偏空** | -25 |
| 小作文情绪 | 利多>0.3 加分 / 利空<-0.3 减分 | ±15 |
| 当日大涨 >2% | 获利了结→减分 | -10 |
| 当日大跌 <-2% | 逢低补货→加分 | +10 |
| 基本面加权 | basis +0.3 / inventory +0.2 / profit +0.2 | |

**行为本质**：月差结构套利者 + 逆势交易者。盯 contango/backwardation，现货商心态（涨了卖、跌了买）。

### 3. institution 纯投机构（clamp: -70 ~ +70）
| 场景 | 行为 | 分值 |
|---|---|---|
| 价涨>1.5%+增仓 | 量价齐升→**追多** | +40 |
| 价跌<-1.5%+增仓 | 放量下跌→**追空** | -40 |
| 涨但减仓 | 空头回补→趋势不确定 | +5 |
| 跌但减仓 | 多头止损→可能见底→偏多 | +10 |
| 5日动量 >5% | 顺势加分 | +15 |
| 5日动量 <-5% | 顺势减分 | -15 |
| 基本面加权 | composite +0.5 | |

**行为本质**：趋势跟随者。动量+量仓确认，最接近"期货基本面/CTA 资金"的现有模型。

### 4. arbitrage 套利商（clamp: -20 ~ +20，天生中性）
| 场景 | 行为 | 分值 |
|---|---|---|
| 远月贴水 >800 | 正套空间→+10 | +10 |
| 远月升水 >500 | 反套空间→-10 | -10 |
| 单日波动 >3% | 波动放大→套利窗口→+5 | +5 |
| 基本面加权 | basis +0.4 / profit +0.2 | |

**行为本质**：纯月差均值回归，评分几乎恒为中性（±20 内），对方向无观点。

### 5. retail 散户/游资（clamp: -60 ~ +60）
| 场景 | 行为 | 分值 |
|---|---|---|
| 当日涨 >2% | 刺激追多 | +25 |
| 当日跌 <-2% | 刺激追空 | -25 |
| 小作文情绪 | >0.4 加分 / <-0.4 减分 | ±15 |
| 放量+涨 | 散户活跃→加分 | +10 |
| 放量+跌 | 恐慌蔓延→减分 | -10 |
| 基本面加权 | sentiment +0.4 / composite +0.2 | |

**行为本质**：纯追涨杀跌+情绪驱动。**当前把散户和游资混在一个 agent 里**——这是与新方案最大的结构差异点。

### 6. resource 锂矿/资源商（clamp: -50 ~ +70，长期偏多）
| 场景 | 行为 | 分值 |
|---|---|---|
| 价格距成本线 <5% | 接近成本→减产预期→**强看多** | +30 |
| 距成本线 5~10% | 成本支撑→+10 | +10 |
| 距成本线 >20% | 远离成本→高利润→看空 | -20 |
| 累库 | 出货压力→减分 | -10 |
| 去库 | 挺价→加分 | +10 |
| 基本面加权 | supply -0.3 / profit +0.4 / inventory -0.2 | |

**行为本质**：成本支撑逻辑，硬编码成本线 125000 元/吨。**与 smelter 高度重合**（权重公式完全一样），独立存在价值低——这是你建议删掉它的依据。

### 7. policy 政策博弈者（clamp: -60 ~ +60）
| 场景 | 行为 | 分值 |
|---|---|---|
| 小作文含政策词（两会/发改委/工信部/新能源/储能/收储/抛储/双碳等） | 政策利多+15 / 利空-15 / 中性+5 | ±15 |
| 价格 >160000 | 政策干预风险→看空 | -20 |
| 价格 <130000 | 政策托底预期→看多 | +10 |

**行为本质**：政策关键词触发 + 价格极端位置干预预期。**不做基本面加权**（fund 逻辑跳过）。

## 二、博弈互动层（所有 agent 共享，非个体行为）

`game_factors.py` 三层博弈：
1. **Layer 1 信息传递**：与自身方向相反的对手盘资金占比越高，自己的评分越往 0 拉（敏感度：retail 0.9 最高、policy 0.2 最低）
2. **Layer 2 行为影响**：同向仓位变动越大，轻微增强自身（跟随效应）
3. **Layer 3 极化检测**：多空比 >3 且平均分 >30 → 触发反转（多数派减分、少数派加分）+ 标记 needs_review → LLM 批量审核

## 三、新 7 主体 vs 现有模型：差异对照

| 新主体 | 现有可复用 | 行为模型差异 | 需要新增 |
|---|---|---|---|
| **上游·冶炼厂** | smelter（保留） | 无差异 | — |
| **下游·正极厂** | ❌ 无对应 | **全新**：现有系统完全没有下游需求侧主体。需设计：排产/采购节奏/库存天数/碳酸锂价格占成本比 | 新 agent 脚本+指标（正极厂开工率、磷酸铁锂/三元排产、碳酸锂采购价容忍度） |
| **贸易商**（现货+屯库+基差+套利+正反套+赌仓单） | merchant + arbitrage（合并强化） | 差异大：①合并套利商职能（月差回归并入）②新增"屯库存"行为（库存周期决策）③新增"赌仓单"行为（仓单注销/注册数据→方向观点）④正套反套观点 | 仓单数据接入（lc_position.db 已有）+ 库存周期状态机 |
| **权益类资金**（券商系，盯锂矿/电池/正极股票指数） | institution（重定义） | 差异大：①输入从"期货量仓动量"改为"A股锂矿/电池/正极指数趋势+板块资金流"②行为模式=中长线慢变量（研报看涨家数变化驱动）③天然偏多（券商研报只写多） | A股指数数据源（akshare 东财概念板块）+ 券商研报看涨家数采集 |
| **期货基本面资金**（盯期货研报观点） | institution（可改造） | 差异：输入改为"期货研报多空家数比"，行为=基本面驱动、交易周期较短 | 期货研报多空家数采集（Zhiji/手动注入起步） |
| **散户**（看K线技术指标） | retail（拆分出） | 差异小：把"游资"拆出去，保留追涨杀跌+情绪，可加入技术指标（均线金叉死叉、RSI、布林） | 技术指标计算 |
| **游资+政策** | retail（游资部分）+ policy（合并） | 差异大：①新增"品种选择"维度——不只看碳酸锂，要评估"碳酸锂在全市场80+品种中的胜率/人气/逻辑清晰度"决定是否介入②中长期逻辑清晰+强胜率+高人气才进场③保留政策敏感（政策利好=强逻辑之一） | 全市场品种机会评估模块（可用 Zhiji 拉多品种行情）+ 游资情绪阈值 |

## 四、结论：现有模型的核心缺陷

1. **没有需求侧**：7 个 agent 全是供给/交易/政策视角，无正极厂/电池厂下游采购主体 → 需求逻辑只能靠 news_sentiment 间接体现
2. **散户和游资混为一体**：retail 同时承担"追涨杀跌"和"投机资金"两个完全不同的行为模式，且无品种选择逻辑
3. **institution 定位模糊**：现有 institution 是"趋势跟随 CTA"，既不是券商权益系也不是期货基本面系，两个新主体的输入源（股票指数/研报家数）都缺失
4. **resource 与 smelter 冗余**：评分逻辑完全同构，删掉合理
5. **博弈互动层与主体耦合弱**：敏感度写死 agent_id，主体重构后需同步调整
