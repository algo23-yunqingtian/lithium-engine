# 碳酸锂简化博弈推演 — 模型假设

> 版本：v1.0 | 创建：2026-09-08 | 文件：`model_lite/params.json`

---

## 1. 模型定位

这是 **7 主体博弈模型的简化版**，用于快速推演和参数调试。完整版（含博弈因子矩阵、信号驱动互动、7 维逻辑评分、心理状态机）见 `engine/` 目录。

**简化策略**：把 7 主体的复杂博弈压缩为 **「价格 vs 成本 vs 库存」三因子** 驱动，每个主体用线性公式自动计算观点评分，用户也可手动覆盖。

---

## 2. 核心假设

### 2.1 价格-成本差（fPriceCost）

| 条件 | 信号 | 逻辑 |
|------|------|------|
| 期货价 < 成本线 | 负 → 利多 | 矿商亏损 → 减产预期 → 供给减少 |
| 期货价 > 成本线 × 1.2 | 正 → 利空 | 高利润 → 增产 → 供给增加 |
| 期货价 ≈ 成本线 | ~0 | 均衡 |

**公式**：`diff = price - cost; fPriceCost = diff > 0 ? min(50, diff/2000) : max(-50, diff/2000)`

### 2.2 库存因子（fInventory）

| 库存水平 | 信号 | 逻辑 |
|----------|------|------|
| < 5 万吨 | +40（利多） | 现货紧张 |
| 5-15 万吨 | 线性 | (10-inv)×8 |
| > 15 万吨 | -40（利空） | 现货充裕 |

### 2.3 政策锚（fPolicy）

| 条件 | 信号 |
|------|------|
| 价格 < 托底价（130,000） | +30（托底预期） |
| 价格 > 干预价（160,000） | -30（调控预期） |
| 其他 | 0 |

### 2.4 现货升贴水（fBasis）

| 条件 | 信号 |
|------|------|
| 升水 > 1,000 | +20（现货紧张） |
| 贴水 > 2,000 | -20（现货宽松） |
| 其他 | basis/100（线性） |

## 3. 主体权重与逻辑

| 主体 | 权重 | 核心逻辑 | 自动公式 |
|------|------|----------|----------|
| 机构 | 30% | 趋势跟随/动量 | fPriceCost × 0.5 + fBasis × 0.3 |
| 冶炼厂 | 20% | 价涨增产→空 | -fPriceCost × 0.6 |
| 贸易商 | 15% | 月差结构 | fBasis × 0.8 + fInventory × 0.2 |
| 矿商 | 15% | 价格贴成本→减产→多 | -fPriceCost × 0.5 + (price<cost ? 30 : 0) |
| 散户 | 10% | 情绪驱动 | fPriceCost × 0.3 + fBasis × 0.2 |
| 套利商 | 5% | 均值回归 | -fBasis × 0.5 |
| 政策 | 5% | 政策锚 | fPolicy |

> 权重设计思路：机构和冶炼厂是价格的主要驱动力（合计 50%），贸易商和矿商反映供需结构（合计 30%），散户提供情绪噪声（10%），套利和政策是修正项（合计 10%）。

## 4. 约束条件

| 参数 | 值 | 说明 |
|------|-----|------|
| 惯性钳制 | ±20/日 | 单日观点变化上限 |
| 止损 | 8% | 跌破成本 8% → 全平 |
| 止盈 | 15% | 涨超成本 15% → 减半 |
| 仓位上限 | 30%/次 | 单次交易上限 |
| 博弈修正 | ±10 | 加权总分上限 |

---

## 5. 信号判定

| 综合评分 | 信号 | 主体分类 |
|----------|------|----------|
| > 5 | 🟢 偏多 | 主体评分 > 15 = 看多 |
| [-5, 5] | 🟡 中性 | |评分| ≤ 15 = 中性 |
| < -5 | 🔴 偏空 | 主体评分 < -15 = 看空 |

---

## 6. 与完整版的差异

| 维度 | 简化版 | 完整版 |
|------|--------|--------|
| 主体数 | 7（同） | 7（计划扩展到 8） |
| 因子数 | 4（价格/成本/库存/升贴水） | 20+（含博弈因子矩阵） |
| 信号互动 | 无 | 7 维逻辑评分 + 信号驱动互动 |
| 心理状态 | 无 | 锚定/买入区间/触发条件 |
| 回测 | 无 | 防透视回测引擎 |
| 数据源 | 用户手动输入 | SMM + 期货 + 现货 + 仓单 |
| 运行方式 | 浏览器内交互 | cron 每日 18:30 |

---

## 7. 使用方法

1. 打开 `pages/model_lite.html`（GitHub Pages 或本地）
2. 调整左侧参数滑块（价格/成本/库存/政策锚/升贴水/成交量）
3. 7 主体评分自动计算，也可手动拖动滑块覆盖
4. 点击「▶ 运行推演」刷新结果
5. 点击「⬇ 导出参数」下载当前参数为 JSON
