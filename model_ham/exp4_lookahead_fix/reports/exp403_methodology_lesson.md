# exp403 方法论专章: 单次静态切分的幸运切点问题

> 本项目方法论经验留存 | 2026-09-09
> 触发事件: HAM因子前视bug修复 + 三版本对照暴露系统性偏差

## 1. 幸运切点问题(Lucky Cut Problem)

**现象**: 第二轮用75/25单次切分, B组HAM因子样本外准确率54.5%(看似优秀)。
第三轮改用严格滚动窗口后, 同一因子准确率降至50.0%——54.5%完全消失。
**根因**: 单次切分只在一个固定切点上评估。当数据存在偶然性结构时,
75%训练/25%测试的切点可能恰好落在模型有利的区间(如恰好选到趋势明显的测试段)。
**本质**: 单次切分的'样本外'其实是'另一个训练集', 不是真正的外推检验。

## 2. 前视bug的隐蔽性

**现象**: ham_model.py 的 docstring 写着'严格使用t之前数据, 不含未来信息',
但代码 `price_change[t-W+1:t+1]` 实际含 `price_change[t]=P(t+1)-P(t)`——注释与代码矛盾。
**修复后**: 纯净版 n_c 从 mean=0.40/std=0.47 塌陷为 mean=0.997/std=0.037(近常数)。
**关键洞察**: 前视不仅是0.7pp的微小偏差, 而是旧因子n_c变化性的**唯一来源**。
原版n_c的'预测力'本质是1日未来价格的回声, 而非真实的投机/产业分歧信号。

## 3. 三条方法论铁律(本项目留存)

1. **禁止单次静态切分做样本外结论**: 必须用滚动窗口/时序walk-forward验证外推能力
2. **注释与代码必须一致核查**: 凡声称'无未来信息'的代码, 逐行核对窗口索引边界
3. **修复后重生成, 不补丁绕过**: 因子有bug时, 必须从源头重算全量因子, 不可只调参掩盖

## 4. 对后续研究的建议

- HAM因子在当前参数(alpha=0.3,beta=0.5,gamma=2,W=20)下**无定量预测价值**
- 市场状态聚类保留**定性价值**, 作为人工研判辅助, 不作自动交易信号
- 如需HAM因子有预测力, 需重设参数空间或换用不同信息集(当前框架下已验证无效)
