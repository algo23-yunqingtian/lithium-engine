## 3. 关键方法论沉淀（最重要的知识）

### 3.1 HAM 突破"塌陷困局"的修复（核心）

历史 exp301-403 失败根因：直接拿 Logit 输出 `n_f_minus_n_c` 做偏离度 → 前视修复后塌陷为常数（std=0.074，720/720天全投机主导）→ 分位触发0交易。

**本次修复**：回到 HAM 原生输入重构偏离度：
```python
D_c = beta * (P_t - P_{t-1})          # 投机趋势动量
D_f = alpha * (P_fund - P_t)           # 产业回归压力
deviation = |D_c_rolling_rank - D_f_rolling_rank|   # 动量与回归压力背离
```
恢复真实变化性（std=0.42）。

**本质区别**：不拿 HAM 预测涨跌方向（前七轮失败点），而是用"系统失衡程度"作变盘触发器。**HAM预测失败 ≠ 状态预警失败**。

### 3.2 基本面动态的关键参数选择

- 开仓：三因子合成强度 |combo| > 滚动180日80%分位（强边际）
- 平仓：边际衰减(combo归零)/预期透支(20日收益超滚动90%分位)/反向信号/18天保护
- **重要教训**：combo 是离散投票信号(±1/3步进)，平仓阈值"回归一半"过于敏感会让持仓过短；基本面是趋势，应待逻辑真正消退（归零/反号）才平

### 3.3 口径对比陷阱（务必注意）

exp407 净值夏普3.62 vs 基本面动态夏普0.57 —— **不可直接比**：
- exp407 = "每日满仓×固定20日折算"连续净值（口径已用 combo×target_fwd 复现验证 acc=0.561/sharpe=3.616 ✓）
- 动态策略 = "择时进出+有空仓期"，空仓收益=0稀释夏普
- 横向对比必须注明口径差异

### 3.4 诚实性纪律

HAM 动态平均持仓1.4天偏短，**未扭曲中性区间参数凑"3-10天"**——这是数据真实反映"系统失衡是瞬时的"。成本敏感性0-0.3%内夏普稳定2.656，结论稳健。
