# 第十轮对话交接文档：下一轮能否继续做 HAM？

> **交接时间**：2026-09-09
> **上一轮**：exp408 条件线性策略（哑变量开关）—— 全样本三项退步，已暂停
> **核心问题**：用户问"下一轮如果继续做 HAM，还可以吗？"
> **回答**：**取决于你突破哪个约束、接受什么风险、愿意付什么代价**。HAM 不是绝对禁区，是"封存分支 + 默认禁用"。

---

## 0. 三句话直答

1. **可以，但不推荐**：HAM 不是物理禁区，是方法论封存。技术上可以解封存、改代码、跑新一轮，但**前七轮已证伪三次**，重做大概率复现失败。
2. **若一定要做，必须先答三个问题**：(a) 新数据/新窗口能否破解前视根因？(b) 是否接受重新走一遍三轮验证流程？(c) 能否接受再次证伪的时间成本？
3. **更划算的方向**：当前最优方案是 exp407 全局等权三因子（夏普3.62、回撤-9.1%），HAM 历史最优也仅持平随机（50-52%准确率）。**突破约束前先想清楚"为什么要重做"，而不是"能不能做"**。

## 2. 前七轮为什么封存 HAM：失败根因速查

| 轮次 | 实验 | 结果 |
|------|------|------|
| 第三轮(exp301-309) | 反向校验+稳健性增强 | 多重检验后 RankIC 全不显著 |
| 第四轮(exp401-403) | 前视泄露修复 | **n_c 修复后塌陷为常数**（std=0.037），信息归零 |
| 第五轮 | GMM 状态聚类 | K=4 稳健，但仅定性、不做预测 |
| 第六轮(exp405) | 因子筛选 | HAM 因子全部剔除 |
| 第七轮(exp406) | 新一代基本面因子 | 禁用 HAM，转向库存/基差/期限结构 |
| 第八轮(exp407) | 叠加稳健性 | 禁用 HAM，三因子等权最优 |
| 第九轮(exp408) | 条件线性(哑变量) | 禁用 HAM，哑变量开关失败 |

### 2.1 三大失败根因（来自 ham_failure_review.md）

1. **工程根因**：HAM 模型存在**前视泄露**（`ham_model.py` line~48），n_c 计算用了未来数据，伪造了因子变化性。修复后 n_c 塌陷为常数，信息量归零。
2. **框架-品种错配**：HAM 框架设计初衷可能不适配碳酸锂这种高波动、产业链复杂的品种。
3. **经济学层面**：HAM 的"主体博弈"假设在碳酸锂市场难以落地——实际市场由库存/基差/期限结构主导，而非理论上的"资金/产业主体博弈"。

### 2.2 关键数据对比

| 指标 | HAM 历史最优 | exp407 全局等权 |
|------|-------------|----------------|
| 样本外准确率 | 50-52%（随机区间） | 56.1% |
| Bonferroni显著项 | 0 | 3（库存/仓单交叉/动力电池） |
| 夏普 | ~0（修复后无信号） | 3.62 |
| 最大回撤 | -27%+ | -9.1% |

## 3. 如果下一轮要做 HAM，需要突破的约束

### 3.1 必须突破的硬约束（清单）

| 约束 | 当前状态 | 突破条件 |
|------|---------|---------|
| HAM 封存规则 | 禁用 | **用户明确授权**突破，更新归档README |
| exp408 不新增因子 | 仅用3因子 | HAM 本质是新因子集，需授权 |
| 不新增因子挖掘 | 仅用exp406保留因子 | HAM 需重新挖掘/验证 |
| 不做非线性模型 | 仅线性加权 | 若用 LightGBM 需授权 |

### 3.2 必须重新跑的流程（不能跳过）

若突破约束，**不能直接用历史 HAM 产物**，必须：
1. 重新做前视泄露审计（exp401 级别）
2. 重新做滚动回测（exp402 级别）
3. 重新做稳健性增强（exp301-309 级别）
4. 重新做多重检验校正
5. 重新做经济学层面分析

**预估耗时**：前七轮 HAM 研究累计花了几十个对话轮次，重做一遍至少需要 3-5 轮完整实验。

### 3.3 必须接受的风险

1. **大概率再次证伪**：前七轮已证伪三次，根因（前视泄露+框架错配）未变
2. **时间成本高**：至少 3-5 轮实验，可能 10+ 轮
3. **机会成本**：当前 exp407 方案夏普3.62，重做 HAM 若失败则无新产出
4. **口径混淆**：HAM 与 exp406+ 口径完全不同，不可横向对比

## 4. 如果要重做 HAM，建议的三条路径

### 路径 A：保守路径（推荐）

**仅做 GMM 定性增强，不做预测**
- 突破约束：无（GMM 已保留）
- 工作量：1-2 轮
- 产出：更精细的市场状态分类，辅助 exp407 策略的事后复盘
- 风险：低
- **适合场景**：你想用 HAM 的"状态识别"能力，但不想碰预测

### 路径 B：激进路径（不推荐）

**完整重做 HAM 预测分支**
- 突破约束：HAM 封存 + 新增因子挖掘 + 可能非线性模型
- 工作量：3-5 轮起
- 产出：新 HAM 版本 + 完整验证报告
- 风险：高（大概率再次证伪）
- **适合场景**：你有新数据/新假设，认为前七轮根因已破解

### 路径 C：折中路径（可考虑）

**用 HAM 的"状态变量"作为哑变量（类似 exp408 思路）**
- 突破约束：HAM 封存（但仅用状态分类，不用预测因子）
- 工作量：1-2 轮
- 产出：GMM 状态 × 基本面因子交互项
- 风险：中（exp408 已证明哑变量开关容易失败）
- **适合场景**：你想试试"状态条件化"，但知道 exp408 教训

## 5. 如果决定不做 HAM，更划算的方向

### 5.1 当前最优方案的进一步提升空间

exp407 全局等权三因子（夏普3.62）仍有提升空间：

| 方向 | 突破约束 | 预估收益 | 风险 |
|------|---------|---------|------|
| **新增基本面因子**（期限结构/成交量持仓） | 本轮"不新增因子挖掘" | 中-高 | 中 |
| **换持有周期**（5日/10日/40日） | 本轮"20日固定" | 中 | 中 |
| **风险平价/最小方差加权** | 本轮"不使用非线性模型" | 中 | 低 |
| **多品种联动**（锂-镍-锌跨品种） | 无 | 高 | 高 |

### 5.2 为什么更推荐这些方向

- **数据已就位**：exp406 已验证库存/基差/动力电池三因子，新增因子只需扩展数据源
- **风险可控**：每轮实验可独立验证，失败不影响已有方案
- **与现有方案兼容**：新因子可叠加到 exp407 框架，不需推翻重来

## 7. 我的建议（明确表态）

**不推荐下一轮重做 HAM 预测分支**。理由：

1. **失败根因未变**：前视泄露（工程）、框架错配（理论）、品种不适配（经济学）三大根因都没解决
2. **机会成本高**：exp407 夏普3.62 已是当前最优，重做 HAM 大概率无新产出
3. **更划算的方向存在**：新增基本面因子、换持有周期、风险平价加权，风险更低收益更确定

**如果用户坚持要做 HAM**，建议走**路径 A（GMM 定性增强）**或**路径 C（状态变量作哑变量）**，避免完整重做预测分支。

**如果用户想突破瓶颈**，建议优先尝试：
1. **新增基本面因子**（期限结构、成交量持仓）—— 数据易得，验证流程成熟
2. **风险平价加权**（突破"非线性"约束）—— 已有理论基础，实现简单
3. **多品种联动**（锂-镍-锌）—— 高潜力但需跨品种数据
