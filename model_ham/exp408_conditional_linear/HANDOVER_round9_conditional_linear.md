## 3. 哑变量设计（关键声明）

### 3.1 D1 高波动哑变量

- **定义**：D1=1 当窗口内20日已实现波动率 > 窗口内70%分位数；否则0
- **波动率口径**：日对数收益的20日标准差，再用180日滚动均值平滑
- **交互项**：`仓单基差×仓单增速 × D1`
- **逻辑**：仓单交叉因子反映资金情绪与套保行为，高波动环境信号更锐利，低波动环境噪声主导

### 3.2 D2 累库哑变量

- **定义**：D2=1 当库存20日环比 > 0（累库）；否则0
- **交互项**：`动力电池20日环比 × D2`
- **逻辑**：动力电池需求因子仅在累库环境有对冲价值；去库时价格由供给端主导

### 3.3 ⚠️ 关键声明

| 维度 | 说明 |
|------|------|
| **哑变量性质** | **环境开关，不是新增独立预测因子**。资金/波动率仅用于构造0-1开关，**不直接作预测因子** |
| **基本面因子** | 仅沿用 exp406 已保留的3个，**零新增** |
| **模型结构** | 等权线性 `w1*库存 + w2*(仓单交叉*D1) + w3*(动力电池*D2)`，**不做参数寻优** |
| **阈值来源** | 仅由窗口内历史分位数生成（70%），**未遍历搜索** |

## 5. 口径与代码细节（重要，避免新对话踩坑）

1. **数据读取**：直接读 `exp406_fund_factor/data/exp406a_factors.csv`，**必须清理 inf**（`F[c].replace([np.inf,-np.inf], np.nan)`）
2. **信号构造**：与 exp406b 完全一致口径——因子值相对滚动训练期中位数方向(+1/-1)，乘IC方向。`IC_SIGN = {库存:-1, 仓单交叉:+1, 动力电池:-1}`
3. **波动率口径**：`rv = log(close/close.shift(1)).rolling(20).std()`，再 `.rolling(180).mean()` 平滑。D1 判定：`vol.iloc[i] > vol.iloc[max(0,i-180):i].quantile(0.7)`
4. **D2 口径**：`f_stock_pct20 > 0` 直接判，无平滑
5. **条件线性信号**：`(sig_stock + sig_wh*d1 + sig_cell*d2) / 3`，等权除以3保持与基准2同量纲
6. **回测口径**：20日持有，连续时序（逐日信号×20日前向对数收益/20折算，净值累乘），年化按250交易日折算。`target_fwd = log(close.shift(-20)/close)`
7. **子样本拆分口径**：`ret20 = log(close/close.shift(20))`；下跌=ret20<-5%；震荡=|ret20|<5%。**阈值选择有主观性**
8. **信号在全量上算再切片**：因滚动窗口需历史数据，子样本回测在全量算信号后按index切片
9. **Bonferroni**：阈值0.05/3=0.0167（3因子）
10. **VIF自计算**：用 numpy lstsq 自实现，避免 statsmodels 依赖
11. **阈值扰动**：仅65%/70%/75%三档，**非网格搜索**

## 7. 风险与局限（已归档到报告）

1. **数据窥探风险**：哑变量假设是事后提出的，存在选择偏差
2. **样本稀疏**：D1触发26.4%、D2触发48.7%，交互项有效窗口数少（10/16）
3. **D2与库存信息重叠**：构造性相关-0.508，开关未引入真正独立信息
4. **等权稀释效应**：哑变量把因子从"始终有效"变"条件触发"，未触发日子信号为0，RankIC被摊薄
5. **下跌段拖累未解决**：高波动段常与下跌段重叠，D1启用的仓单交叉因子在下跌段本身弱
6. **长周期信号，不适用于日内1分钟交易风格**
7. **口径风险**：exp408与exp407同口径可直接对比；与exp405不可横向对比
