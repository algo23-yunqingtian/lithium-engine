## 1. 每日操作流程（SOP）

### 1.1 收盘后（约 15:00~16:00）

```bash
cd /home/ubuntu/lithium-engine
/usr/bin/python3 model_ham/exp429_production/run_daily.py
```

**产出**（写入 `model_ham/exp429_production/data/`）：
- `exp429_daily_pipeline.csv` — 当日 D 因子 + 信号 + 两套仓位
- `exp429_shadow_log.csv` — 追加当日影子盘快照
- `exp429_alert_series.csv` — 更新漂移告警
- `exp429_summary.json` — 全量汇总

**运行检查**（退出码须为 0）：
- 流水线行数 = 交易日数（应为 628 或递增）
- 配置A/B 持仓日数应稳定（历史 232 日）
- 告警分布无异常激增

### 1.2 次日开盘前（约 08:30~08:50）

1. 读取 `exp429_daily_pipeline.csv` 最新行的 `action_A` / `action_B`。
2. 对照 §4 禁止交易场景逐条排查（任一触发 → 当日不开仓）。
3. 对照 §5 止损规则检查持仓浮亏（任一触发 → 执行止损）。
4. 确认监控告警级别（§6）：CRITICAL → 降仓或暂停。

### 1.3 开盘执行（08:59~09:05）

- **执行时点**：9:01 分钟均价（策略标定基准）。
- **滑点预算**：10bp（单侧）。若实际滑点 > 20bp，记录异常并报告。
- **动作映射**：见 §3.2。

### 1.4 盘中监控

- 跟踪持仓浮亏（§5 止损触发线）。
- 关注 ADX：配置A 在 ADX>30 时已自动降权至 30% 仓位。

### 1.5 收盘后

- 运行流水线（回到 §1.1），形成 T+1 决策。
- 更新影子盘日志，与真实成交对照（§7）。

## 2. 两套配置详解

### 2.1 配置A —— 稳健（推荐实盘主力）

| 参数 | 值 |
|:---|:---:|
| ADX 降权 | **保留**（ADX_SCALE = 0.3） |
| 年化收益 | **34.0%**（滚动估参）/ 28.9%（一次性锚点） |
| Calmar | **4.98** |
| 最大回撤 | **−6.8%** |
| 夏普 | 2.293 |
| 笔数 | 135 |
| 日度 IC | +0.219 |

**机制**：当 ADX(14) > 30（强趋势段）时，仓位自动降至 30%。牺牲约 3.4pp 年化，换取约 3.7pp 回撤压缩。

**适用场景**：
- **默认首选**：所有常规交易日。
- 资金性质稳健 / 风控敏感 / 需要高 Calmar 的账户。
- 市场环境不确定、波动率抬升期。
- 新策略上线初期（影子盘对照阶段）。

**禁止场景**：无（配置A 是所有场景的基线，仅 §4 红线触发时暂停）。

### 2.2 配置B —— 激进（高风险高收益）

| 参数 | 值 |
|:---|:---:|
| ADX 降权 | **关闭**（ADX_SCALE = 1.0） |
| 年化收益 | **37.4%**（滚动估参）/ 32.1%（一次性锚点） |
| Calmar | 3.55 |
| 最大回撤 | **−10.5%** |
| 夏普 | 2.212 |
| 笔数 | 132 |
| 日度 IC | +0.241 |

**机制**：关闭 ADX 趋势降权，强趋势段维持满仓，捕捉更强收益，但极端趋势中回撤放大。

**适用场景**：
- 明确单边趋势行情（产业-投机分歧持续放大）。
- 激进资金 / 高回撤容忍账户。
- 配置A 连续错过趋势段（机会成本明显）时短期切换。
- **必须有独立风控**（账户级止损线），不可裸跑。

**禁止场景**：
- ADX(14) > 45（极端强趋势，回撤风险陡增）→ 强制回配置A。
- 监控 CRITICAL 告警期（§6）。
- 波动率 > 历史 95 分位（年化 > 80%）时。

## 3. 信号与仓位解读

### 3.1 D 因子与信号

| 字段 | 含义 |
|:---|:---|
| `D_c` | 投机主体预期（动量追涨/追跌） |
| `D_f` | 产业主体预期（基本面回归压力） |
| `disagreement` | 标准化分歧（D_c_norm − D_f_norm） |
| `deviation` | 分歧强度（|disagreement|），越大越极端 |
| `alpha_t` / `beta_t` | Logit 动态权重（每日滚动估参） |
| `open_signal` | 是否触发开仓（1=是） |
| `signal_dir` | 信号方向（+1 多 / −1 空） |

**核心逻辑**：当产业主体与投机主体预期严重分歧（`deviation` 高）时，HAM 判定市场处于失衡状态，跟随主导一方开仓。

### 3.2 交易动作映射

| action 值 | 含义 | 操作 |
|:---|:---|:---|
| `HOLD_FLAT` | 无持仓 | 不操作 |
| `OPEN_LONG` | 开多 | 9:01 买入 |
| `OPEN_SHORT` | 开空 | 9:01 卖出 |
| `CLOSE` | 平仓 | 9:01 反向平仓 |
| `REVERSE` | 反手 | 平仓 + 反向开仓 |
| `INCREASE` | 加仓 | 增加同向仓位 |
| `DECREASE` | 减仓 | 降低仓位 |
| `HOLD` | 持仓不变 | 不操作 |

### 3.3 仓位刻度

仓位以 0~1 为单位（1 = 满仓基准）。配置A 在 ADX>30 段自动降至 30%。实盘按账户规模折算手数（建议以「单笔风险 ≤ 账户 1%」为基准反推手数）。

## 4. 禁止交易场景（硬性红线）

**任一触发，当日不得新开仓**（已有持仓按 §5 止损/§6 告警处理）：

### 4.1 数据完整性红线

| # | 条件 | 处置 |
|:---:|:---|:---|
| R1 | 流水线运行失败（退出码 ≠ 0） | 当日不开仓，排查修复后重跑 |
| R2 | 当日 P_fund / OHLC 数据缺失 | 当日不开仓，等待数据补齐 |
| R3 | 估参窗口样本 < 60 日（预热期） | 当日不开仓（策略自动用固定参数，但信号不可靠） |

### 4.2 监控告警红线

| # | 条件 | 处置 |
|:---:|:---|:---|
| R4 | 漂移告警 = **CRITICAL** 连续 ≥ 3 日 | 暂停交易，复核因子有效性 |
| R5 | IC_roll < 0 连续 ≥ 5 日 | 暂停交易（因子失效，信号反向） |
| R6 | 配置B 专用：ADX > 45 | 强制切回配置A |

### 4.3 市场环境红线

| # | 条件 | 处置 |
|:---:|:---|:---|
| R7 | 年化波动率 > 80%（历史 95 分位） | 配置B 禁用，仅配置A 且减半仓 |
| R8 | 单日跳空 \|收益\| > 8% | 当日不追单，观望（防假信号） |
| R9 | 节假日/长假前后最后 2 日 | 降仓至 50%（防流动性风险） |
| R10 | 交易所临时停牌/重大政策事件 | 暂停交易，等待市场恢复 |

## 5. 止损规则

### 5.1 单笔止损

| 层级 | 触发线 | 动作 |
|:---|:---|:---|
| 预警 | 单笔浮亏 −3% | 监控，不动作 |
| 止损 | 单笔浮亏 **−5%** | 立即平仓（不分配置） |
| 硬止损 | 单笔浮亏 **−8%** | 强制平仓 + 当日禁止再开仓 |

### 5.2 账户级止损

| 层级 | 触发线 | 动作 |
|:---|:---|:---|
| 预警 | 账户回撤 −5% | 报告，复核 |
| 降仓 | 账户回撤 **−8%** | 全部仓位减半 |
| 熔断 | 账户回撤 **−10%** | 全部平仓 + 暂停交易 5 个交易日 |

> **注**：配置A 历史最大回撤 −6.8%，配置B −10.5%。账户级熔断线（−10%）略高于配置A 历史极值、对齐配置B 极值——配置B 账户必须接受这一风险敞口。

### 5.3 时间止损

- 持仓超过 **15 个交易日**且浮盈 < +2%：考虑平仓（信号未兑现，资金效率低）。
- 持仓超过 **25 个交易日**：强制平仓（信号过期）。

### 5.4 波动率止损

- 持仓期间年化波动率突破 100%：减仓 50%，等待波动收敛。

## 6. 监控与漂移告警响应

### 6.1 三维度告警

| 维度 | 监控指标 | WARNING | CRITICAL |
|:---|:---|:---:|:---:|
| 因子 IC | pos vs 次日收益滚动相关 | < 0.05 | < 0.0 |
| D 分布 | deviation 滚动中位数 | > 0.95 | > 1.05 或 < 0.25 |
| Logit 权重 | α/β 滚动 CV | > 0.50 | > 0.80 |

历史分布（2024-08 起）：OK 67% / WARNING 20% / CRITICAL 13%。

### 6.2 响应动作

| 告警级别 | 响应 |
|:---|:---|
| **OK** | 正常交易 |
| **WARNING** | 监控加强，准备降仓；连续 3 日 WARNING → 主动降仓 30% |
| **CRITICAL** | 立即降仓 50%；连续 3 日 → 暂停交易（触发 R4） |

### 6.3 告警语义解读

- **IC 走低**：分歧信号与实际收益脱节，因子可能漂移 → 最严重，直接关系策略有效性。
- **D 分布过高**：市场持续极端失衡（趋势盲区风险），HAM 可能追在极端后段。
- **D 分布过低**：无交易机会，策略应空仓（非亏损，是机会成本）。
- **权重 CV 过高**：产业/投机主导权剧烈切换，市场结构变化 → 模型可能不适应。

## 7. 影子盘与实盘对照

### 7.1 影子盘机制

`exp429_shadow_log.csv` 记录每日信号快照（D 因子、方向、两套仓位、动作、活跃状态）。实盘每日运行流水线后自动追加。

### 7.2 对照纪律

| 检查项 | 频率 | 标准 |
|:---|:---:|:---|
| 信号方向一致率 | 周 | 实盘 vs 影子盘 ≥ 95% |
| 成交滑点偏差 | 周 | 实际滑点 vs 10bp 预算，偏差 < 50% |
| 净值偏离 | 月 | 实盘 vs 影子盘净值相关 ≥ 0.95 |
| 漏执行/错执行 | 日 | 零容忍，逐笔核对 |

### 7.3 影子盘失效处置

若实盘与影子盘净值相关 < 0.9（连续 1 月）：
1. 排查执行偏差（滑点/时滞/漏单）。
2. 排查数据偏差（P_fund 更新滞后）。
3. 必要时回退到一次性参数模式复核。

## 8. 故障排查与应急

### 8.1 常见故障

| 症状 | 排查 |
|:---|:---|
| 流水线报 import 错误 | 确认用 `/usr/bin/python3`（非 venv），工作目录为 `/home/ubuntu/lithium-engine` |
| 流水线报数据缺失 | 检查 P_fund 数据源（lc_spot.db）是否更新 |
| 绩效偏离锚点 | 检查 9:01 成交价标定文件是否存在，种子固定 20260910 |
| 告警激增 | 检查监控数据是否异常（可能是数据问题非真漂移） |

### 8.2 应急回退

- **紧急暂停**：直接停止运行流水线，不执行次日动作。
- **回退参数模式**：将 `ham_pipeline.py` 的 `build_disagreement_series()` 替换为 `E409.compute_system_deviation()`（一次性固定参数），牺牲滚动优势换取稳定性。
- **恢复操作**：修复后重跑，确认产出行数与锚点一致。

### 8.3 环境备忘

- Python：`/usr/bin/python3`（3.12，含 pandas/scipy/numpy）。
- 工作目录：`/home/ubuntu/lithium-engine`。
- LSP/Pyright 的 `Import ... could not be resolved` 报错为动态 sys.path 导入误报，**全部忽略**。
- 9:01 成交价标定固定种子 20260910，确保跨运行可复现。
