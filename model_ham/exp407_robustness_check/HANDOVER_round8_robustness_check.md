## 4. 口径与代码细节（重要，避免新对话踩坑）

1. **数据读取**：直接读 `exp406_fund_factor/data/exp406a_factors.csv`，**必须清理 inf**（原exp406a未清理，行189/271等有inf，会影响相关系数计算）。代码：`F[c].replace([np.inf,-np.inf], np.nan)`
2. **信号构造**：与 exp406b 完全一致口径——因子值相对滚动训练期中位数方向(+1/-1)，乘IC方向。`IC_SIGN = {库存:-1, 仓单交叉:+1, 动力电池:-1}`
3. **回测口径**：20日持有，连续时序（逐日信号×20日前向对数收益/20折算，净值累乘），年化按250交易日折算。`target_fwd = log(close.shift(-20)/close)`
4. **子样本拆分口径**：`ret20 = log(close/close.shift(20))`；下跌=ret20<-5%；震荡=|ret20|<5%。**阈值选择有主观性**（报告已标注）
5. **信号在全量上算再切片**：因滚动窗口需历史数据，子样本回测在全量算信号后按index切片，保证滚动训练窗口不被截断
6. **Bonferroni**：阈值0.05/3=0.0167（3因子）
7. **VIF自计算**：用 numpy lstsq 自实现，避免 statsmodels 依赖
8. **IC-IR加权**：`IC-IR = mean(IC)/std(IC)`，取绝对值作权重再归一化

1. **基准核心**：库存20日环比（稳健核心，跨周期稳定）
