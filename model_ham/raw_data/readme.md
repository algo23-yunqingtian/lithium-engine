# 原始输入数据说明

| 文件 | 来源 | 频率 | 时间范围 | 说明 |
|------|------|------|----------|------|
| lithium_future.csv | lithium.db prices 表 | 日频 | 2023-07-21 ~ 2026-09-07 | LC0 主力合约 OHLCV + 持仓 + 结算价 |
| fundamental_balance.csv | lithium.db lithium_weekly 表 | 周频 | 2023~2026 | SMM 库存/产量/开工率/电芯产量（需前向填充为日频） |
| spot_price.csv | lc_spot.db spot_price 表 | 日频 | 2023-07-21 ~ 2026-07-30 | SMM 现货价格 + 近月/远月基差 |
| smm_daily.csv | lithium.db lithium_daily_prices 表 | 日频 | 2006~2026 | SMM 现货均价 + 期现价差 |

## 数据源
- SMM（上海有色网）：库存、产量、开工率、电芯产量、现货价格
- 期货交易所：主力合约价格、持仓
- 东方财富：库存历史（inventory_history 表，仅 2026-04~07）

## 关键指标映射（周度 col_idx）
- 2: 碳酸锂大样本库存: 总计（吨）
- 6: 碳酸锂样本库存: 总计（吨）
- 7: 库存周期指数: 总计（天）
- 11: 四地社会库存: 沪苏赣川（吨）
- 12: 碳酸锂产量: 总计（吨）
- 17: 碳酸锂开工率: 总计（%）
- 23-25: 动力电芯产量: 三元/铁锂/总（GWh）
