### spread_near1_near3 定义

- **near1** = 当日排序第1的近月合约（距离到期最近的活跃可交割合约）
- **near3** = 当日排序第3的近月合约（距离到期第三近的活跃可交割合约）
- spread = near1收盘价 − near3收盘价
- **动态滚动**：合约随时间滚动切换，非固定 LC01/LC03
- 缺失日：0 天（活跃合约不足3个），标记 NaN，**未插值**

## 6. 局限性

1. **spread_near1_near3 缺失 107 天（14.1%）**：活跃合约不足 3 个时标记 NaN，未插值
2. **测试集状态分布可能失衡**：部分 State 测试样本过少，统计可信度不足
3. **K 仅在 [2,3,4] 内选**：BIC 单调下降，非全局最优断言
4. **GMM 高斯假设**：金融序列厚尾非平稳，状态边界为概率软划分
5. **仓单库存≠社会库存**：用交易所显性仓单代理，系统性低估真实库存
6. **全部结果为样本内统计观察**，不代表样本外预测有效性
