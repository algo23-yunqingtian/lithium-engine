## 一、原始研究思路

### 1.1 HAM 异质交易者模型设计初衷

HAM 基于 **Brock-Hommes** 异质 Agent 模型（Heterogeneous-Agent Model），为碳酸锂期货设计双主体博弈框架：

- **产业基本面 Agent（Agent F）**：锚定供需公允价格 `P_fund`，向公允价值回归。代表产业链产业资本的理性定价行为。
- **投机趋势 Agent（Agent C）**：基于价格动量追涨杀跌。代表期货投机的趋势跟随行为。

**策略切换机制**：两类 Agent 根据历史滚动收益动态调整市场占比，采用 Logit 权重函数（参数 γ 控制灵敏度）。

### 1.2 理论假设

| 假设 | 内容 |
|------|------|
| 价格形成 | 市场价格由两类 Agent 的加权决策共同决定 |
| 占比动态 | Agent 占比随历史表现滚动调整，Logit 切换 |
| 投机主导→波动放大 | 投机 Agent 占比越高，行情越脱离基本面，波动率越大 |
| 分歧信号 | 产业-投机力量分歧是行情方向的领先信号 |

### 1.3 想要捕捉的市场博弈信号

衍生 3 个核心因子：

| 因子 | 含义 | 原始设计意图 |
|------|------|------------|
| `n_c` | 投机 Agent 市场占比 | 越高→波动率越大→行情脱离基本面 |
| `Total_Demand` | 聚合超额需求 | 正→多头压力，负→空头压力 |
| `n_f - n_c` | 产业-投机力量分歧 | 正→产业主导，负→投机主导 |

**研究预期**：通过刻画投机力量占比和市场博弈结构，建立碳酸锂价格涨跌的领先预测信号。

## 二、工程层面问题：前视泄露

### 2.1 前视泄露问题

**漏洞位置**：`ham_model.py` 第 48 行（profit 窗口）

```python
# ❌ 含前视（原版）
window_price_change = price_change[t-W+1:t+1]   # 含 price_change[t] = P(t+1) - P(t)

# ✅ 修复后
window_price_change = price_change[t-W:t]        # 最大价格索引 t，无 P(t+1)
```

`price_change[t] = P(t+1) - P(t)` 引用了 **t+1 日未来价格**，构成 1 日前视泄露。

### 2.2 修复前后 n_c 指标对比

| 因子 | 原版（含前视） | 纯净版（修复后） | 变化 |
|------|------------|--------|------|
| **n_c** | mean=0.40 / std=0.47 | mean=0.997 / std=0.037 | ⚠️ **塌陷为近常数** |
| **n_f - n_c** | mean=0.19 / std=0.95 | mean=-0.99 / std=0.07 | ⚠️ **全投机主导（716/720天）** |
| Total_Demand | mean=-102.9 | mean=-28.2 | 相关 0.52 |
| profit_f | — | — | 相关 0.48 |

**最关键发现**：修复前视后，`n_c` 从 `std=0.47` **塌陷为 `std=0.037` 近常数**——原版 `n_c` 的"变化性"几乎完全由那 1 日未来价格泄露撑起，修复后信息含量归零。

> 第三轮曾量化"前视虚高 0.7pp"，认为非致命。第四轮修复全套重跑后证明：**前视不是偏差，而是旧因子预测力的唯一来源**。

### 2.3 前视相关性量化

- 含前视版 vs 纯净版 `n_c` 相关系数仅 **0.015**（几乎不相关）
- 这证明两个版本的 `n_c` 实质上是不同变量，前视版是伪造的"变化性"

## 三、稳健性检验结果

### 3.1 静态切分 vs 滚动窗口对比

| 版本 | 样本外准确率 | HAM 因子 | 关键特征 |
|------|------------|---------|---------|
| 旧单次切分（75/25，第二轮） | **54.5%** | 含前视 | 幸运切点 |
| 旧滚动（exp306） | **50.0%** | 含前视 | 54.5% 完全消失 |
| 修复后滚动（exp402） | **52.1%** | 纯净 | 因子塌陷，确认无预测力 |

**核心结论**：第二轮最得意的 **54.5% 是"幸运切点"**——在严格滚动窗口（17 窗口/340 行）下**完全消失至 50.0%**。

### 3.2 样本内外信号反转

- **n_f - n_c 样本内外方向翻转**：训练集与测试集分层收益相关系数 **-1.000**（完全相反），该因子过拟合训练集
- **A 组训练集 83% / 样本外 45.5%**：训练集严重过拟合被上一轮掩盖
- **纯净版 n_f-n_c 塌陷**：修复后 716/720 天全投机主导，剔除与否对滚动结果**完全无影响**（52.1%/77.1%/-24.88% 两组一致）

### 3.3 多重检验校正结论

- Bonferroni 校正（p<0.0014，3 因子）后：**RankIC 显著项 = 0**
- 上一轮"2 项 RankIC 显著"是样本内过拟合产物
- exp402 滚动样本外：三因子 / 两因子对照 **RankIC 显著项均为 0**

### 3.4 回测结果（exp402 修复后滚动，样本外）

| 指标 | 对照1（三因子） | 对照2（两因子） | 固定多头基准 |
|------|--------------|--------------|-------------|
| 方向准确率 | 52.1% | 52.1% | — |
| 总收益 | +77.1% | +77.1% | +60.4% |
| 最大回撤 | -24.88% | -24.88% | -34.78% |
| RankIC 显著项 | **0** | **0** | — |

- 对照1 与对照2 **完全一致** → `n_f_minus_n_c` 为纯噪声
- 多空年化 77.1% > 多头 60.4%，但 **依赖滚动区间，非稳健超额**；准确率 52.1% 仍在随机区间

## 四、经济学层面失效分析

### 4.1 HAM 模型的适用边界

HAM（Brock-Hommes 框架）理论上适用于：
- 同质市场参与者可清晰区分为少数几类 Agent
- Agent 占比可观测或可从价格行为稳定反演
- 市场具有相对稳定的 Agent 切换动力学
- 样本量足以识别参数（需较长序列）

### 4.2 为什么该理论框架很难落地碳酸锂短期预测

1. **参数在碳酸锂上无稳定解**：纯净 `n_c` 塌陷为 `std=0.037` 常数，说明在 (α=0.3, β=0.5, γ=2, W=20) 下 Logit 切换几乎恒定为"投机主导"——参数在该市场下退化，换参数未必改变结论。

2. **投机占比不可观测**：模型假设的 Agent 占比需从价格行为反演，但碳酸锂价格受政策、库存、新能源需求等外部冲击主导，投机占比信号被基本面噪声淹没。

3. **样本量不足**：533 行有效数据 / 17 滚动窗口，Brock-Hommes 多参数模型（4 参数）统计效力严重不足，过拟合风险极高。

4. **市场微观结构不匹配**：Brock-Hommes 框架源于成熟金融市场（股市、汇市），碳酸锂作为新兴商品期货，产业资本（占主导）与投机力量行为模式与经典框架假设差异大。

5. **1 日前视是结构性依赖**：原版因子变化性完全来自前视，修复后归零，说明模型本身不产生真实预测信息——是伪装的"有信号"。

### 4.3 失效根因总结

HAM 在碳酸锂上的失败不是参数调优问题，而是**框架-品种错配**：
- 工程层面：前视泄露伪造了因子变化性
- 经济学层面：参数退化 + 样本不足 + 市场结构不匹配
- 结果：即使修复所有工程 bug，因子仍无真实预测力

## 五、明确区分：学术价值 vs 预测适用性

| 维度 | HAM 理论 | HAM 衍生因子（预测用途） |
|------|---------|----------------------|
| 学术解释价值 | ✅ **有** | — |
| 市场博弈结构刻画 | ✅ **有**（识别投机占比变化、Agent 分歧） | — |
| 碳酸锂涨跌预测 | — | ❌ **无** |
| 定量因子有效性 | — | ❌ 三轮验证均无预测力 |
| 适用边界 | 理论框架本身成立 | 不适合做碳酸锂短期涨跌预测 |

**明确结论**：
- **HAM 理论有学术解释价值**：Brock-Hommes 框架在市场博弈结构刻画上仍有理论意义，可作为市场微观结构研究的参考。
- **HAM 衍生因子不适合做碳酸锂涨跌预测**：`n_c` / `Total_Demand` / `n_f-n_c` 经三轮严格验证（前视修复 + 滚动窗口 + 多重检验校正）均无真实预测力，不应再用于预测。

## 六、最终结论

### 6.1 HAM 预测分支终止

**HAM 相关预测方向正式终止，不再继续开发。** 理由：
1. 三轮实验（第三轮稳健性、第四轮前视修复、第五/六轮定性）均证明 HAM 因子无真实预测力
2. 前视泄露是旧因子预测力的唯一来源，修复后归零
3. 框架-品种错配是结构性问题，非调参可解
4. 继续迭代是无效投入

### 6.2 GMM 聚类保留，仅定性

**GMM K=4 市场状态聚类保留，但仅用于定性市场复盘，不做预测：**
- K=4 划分稳健（状态持续性 85%、对 K 不敏感）
- 4 状态画像有定性参考价值（S0 低持仓中性 / S1 高库存弱价差 / S2 高价差高波 / S3 高波动高基差）
- **不基于 GMM 状态做涨跌预测或交易信号**

### 6.3 后续工作方向

1. **HAM 预测任务全部暂停**：后续实验不再调用 HAM 任何函数、变量（`n_c` / `n_f` / `Total_Demand` / `profit_*` / `D_f` / `D_c` / `P_fund` 等）
2. **工作重心转向挖掘新的基本面因子**：基本面（库存、基差、期限结构、成交量持仓）方向
3. **GMM 仅作定性辅助**：用于市场复盘解读，不作预测

## 七、方法论铁律沉淀（供后续实验遵守）

1. **滚动窗口优先于单次切分**：单次 75/25 切分极不可靠（第二轮 54.5% 是幸运切点），必须用滚动窗口（17 窗口）评估样本外表现。
2. **修复前视后必须重生成全部因子**：修了代码不重跑等于没修；旧因子不可复用。
3. **注释与代码一致性核查**：第四轮发现注释声称"无未来信息"但代码实际含前视——注释不是事实依据，必须逐行核查。
4. **多重检验校正必做**：单因子 RankIC 需 Bonferroni 校正，避免样本内过拟合假显著。
5. **塌陷即失效**：修复后因子 std 塌陷为近常数 = 信息含量归零，是失效的强信号。
6. **框架-品种适配性优先**：理论框架落地前需评估品种微观结构匹配度，错配时调参无效。
