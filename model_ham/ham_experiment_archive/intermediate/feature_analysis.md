4. **标签一致性**：测试集标签使用测试集内部数据计算，不参与调参

## 6. 实验局限性

### 特征缺失影响

1. **仓单库存 (warehouse_inventory)**: 仅覆盖 84 天（2026-05-06 ~ 2026-09-01），占样本 11.4%。
   - 影响：无法在全样本上评估仓单库存对价格的影响，ML 模型需处理缺失值（插值或特征掩码）
   - 建议：若仓单库存对模型有贡献，可考虑单独训练子样本模型

2. **社会库存 (social_inventory)**: 仅覆盖 67 天（2026-04-20 ~ 2026-07-27），占样本 9.1%。
   - 影响：社会库存是碳酸锂供需平衡的核心指标，大面积缺失严重削弱基本面因子
   - 建议：需人工提供完整序列

3. **冶炼开工率**: 未获取到，无法纳入数据集。
   - 影响：供给侧压力无法量化，ML 对照组缺少关键的供给端特征
   - 建议：需人工提供（SMM 周频或月频数据）

4. **正极排产**: 未获取到，无法纳入数据集。
   - 影响：需求侧评估不完整，无法量化正极材料排产对碳酸锂需求的影响
   - 建议：需人工提供（月频数据）

### 对照实验影响

- **纯 HAM 因子模型**: 可正常运行（n_c, Total_Demand, n_f-n_c 全样本有效）
- **HAM + 量价特征**: 可正常运行（close, volume, position, basis, spot_avg 全样本有效）
- **HAM + 基本面指数**: 部分可用（fundamental_indices 覆盖大部分样本，但 fi_inventory 等缺失较多）
- **HAM + 完整传统特征**: 受限于库存、开工率、排产数据缺失，对照组特征不完整
- **结论**: HAM 因子本身足以作为 ML 特征独立评估，但与传统 ML 模型的对比实验将因外部特征缺失而不完整

### 数据质量说明

- **HAM 因子**: 确定性公式输出，全样本有效（740天），无未来函数
- **量价数据**: 来自 LC0 主力连续合约，全样本有效
- **基差/现货**: 来自 SMM 现货数据前向填充，全样本有效（部分日期为填充值）
- **标签**: 严格使用 t 时刻之后的收益率，无未来函数
