## 3. 稳健结论 vs 偶然噪声

### 稳健结论(可信赖)

1. **GMM聚类K=4稳健**: 三轮均BIC选K=4, 状态持续性85%
2. **条件RankIC普遍不显著**: Bonferroni后三轮均0项显著
3. **n_f_minus_n_c无预测力**: 修复前视后塌陷为常数, 剔除无影响
4. **样本外准确率均在50%附近**: HAM因子无稳定方向预测力
5. **聚类定性价值**: 市场状态标签(涨/跌/震荡/极端)对人工研判有参考价值

### 偶然噪声(不可信赖)

1. **B组54.5%**: 单次幸运切点, 滚动下消失
2. **旧版n_c变化**: 几乎全靠1日前视撑起, 非真实预测力
3. **上一轮'2项RankIC显著'**: 样本内假象
4. **多空优于多头(部分)**: 依赖具体滚动区间, 非稳健超额

## 4. 定量预测能力边界声明

- **市场状态聚类的定性价值**: GMM能稳定划分4种市场状态(持续性85%), 对人工研判市场阶段有参考价值——这是**定性**贡献
- **HAM因子定量预测能力的边界**: 修复前视后, n_c/n_f-n_c塌陷为常数, 滚动样本外准确率≈50%, RankIC不显著——**定量预测能力不成立**
- **结论**: 聚类可做定性辅助, HAM因子不应作为定量预测信号使用
